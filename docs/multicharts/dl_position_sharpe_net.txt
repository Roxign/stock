{ =====================================================================
  dl_position_sharpe_net ── 成本感知部位網路（Sharpe 目標，只做多，0 / 25 / 50 / 75 / 100%）
  ---------------------------------------------------------------------
  這個策略的模型（5 個種子的小型 MLP 集成，每個 1,601 個參數，共 8,005 個；
  輸入 32 個特徵，其中 15 個是市場背景：50 檔等權重大盤、加權指數、費半、
  那斯達克、台積電 ADR、VIX、美元/台幣）需要美股與匯率資料，而且每年 1 月 1 日
  要重新訓練，無法在 PowerLanguage 裡重算。所以由 Python 每天算好「每檔股票的
  目標曝險」，匯出成 ASCII 價格檔，在 MultiCharts 當作第二個商品 (data2) 讀進來交易。

  data2 的收盤價 = 100 + 100 × 目標曝險
      100 = 空手、125 = 25%、150 = 50%、175 = 75%、200 = 全額持有
  （加 100 是為了讓價格永遠為正數，QuoteManager 不接受 0 或負的價格。）
  這根 K 棒收盤後決定、下一根 K 棒開盤成交，與 Python 回測（stocklab/backtest.py）
  的時點完全相同。

  ── 使用步驟 ──────────────────────────────────────────────────────
  1. 每個交易日收盤、資料更新後（data/raw 已含當天日線；外部資料含當晚美股收盤，
     所以請在台北時間隔天早上約 06:00 以後、09:00 開盤以前執行），在 repo 根目錄執行：
        C:\Users\user\.venvs\stock\Scripts\python.exe -m strategies.dl_position.export_signals
     約 2～3 分鐘（重跑 2012 年起每年一次的 walk-forward 訓練；只用 CPU、2 個執行緒）。
     輸出：C:\Users\user\OneDrive\Desktop\stock\exports\dl_position_sharpe_net\<代號>_DLP.csv
     格式：Date,Time,Open,High,Low,Close,Volume，例如 2026/10/02,13:30:00,200,200,200,200,1
     （O = H = L = C；Volume 固定 1）。程式最後會列出每檔「最新目標」與要加碼／減碼的股票，
     也可以直接照表手動下單。
  2. QuoteManager：Import Data → ASCII，每個檔案匯入成一個新商品，
     商品名稱建議 DLP_<代號>（例如 DLP_2330），日線 (Daily)，
     欄位順序 Date, Time, Open, High, Low, Close, Volume，日期格式 YYYY/MM/DD，
     交易時段與台股相同。第一次建立後，之後每天重新匯入（覆蓋）即可。
  3. 圖表：data1 = 個股日線（還原權值），Insert Symbol 加入 DLP_<代號> 當 data2
     （同為日線；可放在隱藏的子圖）。兩者交易日必須一致。
  4. 套用本訊號。只有 data2 的日期等於 data1 當根日期時才更新目標曝險；
     若某天訊號檔缺資料，沿用前一天的目標（並請檢查是否忘了重新匯入）。
  5. 2010～2011 年（還沒有模型）以及新上市股票前約 20 根 K 棒（波動度還算不出來），
     訊號檔給 200（全額持有），與 Python 回測一致。

  ── Strategy Properties ──────────────────────────────────────────
    1. 日線、還原權值（除權息調整）價格。
    2. Commission：買賣各 0.1425%；證交稅：賣出 0.3%。若無法只對賣出收稅，
       可用「雙邊各 0.2925%」近似（來回 0.585%，與 Python 回測相同）。
    3. Slippage：依實際情況設定（Python 回測未計滑價，以隔日開盤價成交）。
    4. Position Limits：勾選「Allow up to 4 entry orders in the same direction
       as the currently held position ─ when the order is generated by a
       different entry order」。"Q1"～"Q4" 是四個不同的進場單，各代表 25%。
    5. Initial Capital 例如 1,000,000；MaxBarsBack 設 5 即可（不需要歷史計算）。

  ── 近似與差異 ───────────────────────────────────────────────────
    ‧ Python 回測每天把部位調整到「目標曝險 × 當時權益」；這裡在進場當下以
      權益的 25% 為一單位買進，持有期間不再每天再平衡，數量會因股價漲跌而偏離
      目標，報酬會與 Python 回測略有差異。
    ‧ 零股 (LotSize = 1) 最接近回測；整張 (LotSize = 1000) 對高價股誤差較大
      （25% 一單位可能不到一張）。
    ‧ 訊號檔每天重算整段歷史，但每年的模型只用該年 1 月 1 日以前已知的資料訓練，
      過去的訊號不會因為新資料而改變（已通過截斷前視檢查，0 根 K 棒不同）。
  ===================================================================== }

inputs:
    LotSize(1);          { 下單單位股數：1 = 零股，1000 = 整張 }

vars:
    Target(1), Eq(0), QtrQty(0);

{ ---- 讀取 data2 的目標曝險：(收盤價 - 100) / 100，四捨五入到 0.25 ---- }
if Date of data2 = Date and Close of data2 >= 100 then
    Target = Round((Close of data2 - 100) / 25, 0) * 0.25;

{ ---- 下單：四個 25% 單位 "Q1"～"Q4"，下一根開盤市價成交 ---- }
Eq = InitialCapital + NetProfit + OpenPositionProfit;
QtrQty = IntPortion(0.25 * Eq / Close / LotSize) * LotSize;

if Target >= 0.125 then begin
    if QtrQty > 0 then Buy ("Q1") QtrQty shares next bar at market;
end
else
    Sell ("Q1X") from entry ("Q1") next bar at market;

if Target >= 0.375 then begin
    if QtrQty > 0 then Buy ("Q2") QtrQty shares next bar at market;
end
else
    Sell ("Q2X") from entry ("Q2") next bar at market;

if Target >= 0.625 then begin
    if QtrQty > 0 then Buy ("Q3") QtrQty shares next bar at market;
end
else
    Sell ("Q3X") from entry ("Q3") next bar at market;

if Target >= 0.875 then begin
    if QtrQty > 0 then Buy ("Q4") QtrQty shares next bar at market;
end
else
    Sell ("Q4X") from entry ("Q4") next bar at market;
