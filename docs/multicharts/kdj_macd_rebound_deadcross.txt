{ ================================================================================
  kdj_macd_rebound_deadcross：KDJ 與 MACD 在零軸下同步翻揚買進、零軸上 K 值下彎且 MACD 死亡交叉才賣出，
  10% 收盤停損（只做多，部位 0 或 100%）
  --------------------------------------------------------------------------------
  與 kdj_macd_rebound_turn 只差在賣出條件的「MACD 往下」：這裡解讀為 MACD 死亡交叉
  （DIF 由上往下跌破 MACD 線），而不是柱狀體一縮短就賣，所以抱得比較久。

  規則（日K，每根K棒收盤後判斷，下一根K棒開盤以市價成交）：
    買進：同一根K棒上
          (1) KDJ 開始反彈：K 值勾頭向上（今天 K > 昨天 K，且昨天 K <= 前天 K）
          (2) MACD 開始反彈：柱狀體 OSC = DIF - MACD 勾頭向上（綠柱開始縮短；今天 OSC > 昨天，且昨天 <= 前天）
          (3) MACD 為負：DIF < 0 且 MACD 線 < 0（兩條線都在零軸下）
    賣出：同一根K棒上
          (1) KD 往下：K 值勾頭向下（今天 K < 昨天 K，且昨天 K >= 前天 K）
          (2) MACD 往下：MACD 死亡交叉（今天 DIF < MACD 線，且昨天 DIF >= MACD 線）
          (3) MACD 為正：DIF > 0 且 MACD 線 > 0（兩條線都在零軸上）
    停損：進場價 = 買進訊號隔天的開盤價。從進場那根K棒的收盤開始，
          只要收盤價 < 進場價 x (1 - StopPct/100)，就在下一根K棒開盤賣出。
          這是「收盤確認」的停損，與 Python 回測一致；請不要改用 SetStopLoss
          （SetStopLoss 會在盤中觸價就出場，回測結果會不同）。
    停損或賣出後，下一次買進需要重新出現買進訊號。

  KDJ（台灣 9,3,3，1/3 平滑，初值 50）：
    RSV = (收盤 - 9日最低) / (9日最高 - 9日最低) * 100（最高 = 最低時 RSV = 50）
    K = 前K * 2/3 + RSV / 3；D = 前D * 2/3 + K / 3；J = 3K - 2D
  MACD（12,26,9）：DIF = EMA12 - EMA26；MACD 線 = DIF 的 EMA9；OSC = DIF - MACD 線

  Inputs：
    KLen               KDJ 的 RSV 天數（預設 9；K、D 平滑固定為 1/3）
    MacdFast/Slow/Sig  MACD 參數（預設 12 / 26 / 9）
    StopPct            停損百分比（預設 10，代表收盤跌破進場價 10% 停損）
    Capital            計算下單股數用的本金，請與 Strategy Properties 的 Initial Capital 相同

  注意：
    - 請在 Strategy Properties 設定交易成本：手續費買賣各 0.1425%（依券商折扣調整），
      證交稅賣出 0.3%（若無法只對賣方收稅，可把每邊佣金多加 0.15% 近似），以及合理滑價。
    - Python 回測使用還原權值（除權息調整）日線；MultiCharts 若使用未還原資料，
      除權息缺口會讓 KDJ、MACD、停損與訊號略有不同。
    - 指標需要暖機，請至少載入 100 根以上歷史K線；最前面幾十根的指標值可能與 Python 不同。
    - 下單股數 =（本金 + 已實現損益）÷ 收盤價，取整數股（零股）；若只交易整張請改成 1000 股的倍數。
    - 研究結果（50 檔中位數，詳見 RESEARCH.md）：樣本內 2010–2020 CAGR 6.4% / Sharpe 0.42
      （買進持有 8.8% / 0.48）；樣本外 2021–2026 CAGR 18.4% / Sharpe 0.80（買進持有 35.7% / 1.10）；
      8 折交叉驗證 0/8 折 Sharpe 勝過買進持有。回測結果不代表未來績效，也不是投資建議。
    - 這支程式已逐行翻譯回 Python 逐根模擬：從第 1 根開始計算時，與 Python 回測的部位
      在 50 檔上完全一致；若 MaxBarsBack 讓計算從第 10 根才開始，因 EMA 起點不同，
      約 0.3% 的K棒（暖機後）部位會不同。
  ================================================================================ }

Inputs:
	KLen(9),
	MacdFast(12),
	MacdSlow(26),
	MacdSig(9),
	StopPct(10),
	Capital(1000000);

Vars:
	rsv(50), kv(50), dv(50), jv(50), hh(0), ll(0),
	dif(0), macdv(0), osc(0),
	kdjUp(false), macdUp(false), kdDn(false), macdDead(false),
	buySig(false), sellSig(false),
	inTrade(false), barsIn(0), entryPx(0), shs(0);

{ ---- 台灣 KDJ（9,3,3，1/3 平滑，初值 50；J = 3K - 2D） ---- }
hh = Highest(High, KLen);
ll = Lowest(Low, KLen);
if hh - ll <> 0 then
	rsv = (Close - ll) / (hh - ll) * 100
else
	rsv = 50;
kv = kv[1] * 2 / 3 + rsv / 3;
dv = dv[1] * 2 / 3 + kv / 3;
jv = 3 * kv - 2 * dv;

{ ---- MACD：DIF = EMA12 - EMA26，MACD 線 = DIF 的 EMA9，柱狀體 OSC = DIF - MACD 線 ---- }
dif = XAverage(Close, MacdFast) - XAverage(Close, MacdSlow);
macdv = XAverage(dif, MacdSig);
osc = dif - macdv;

{ ---- 開始反彈 / 開始往下 ---- }
kdjUp    = kv > kv[1] and kv[1] <= kv[2];
macdUp   = osc > osc[1] and osc[1] <= osc[2];
kdDn     = kv < kv[1] and kv[1] >= kv[2];
macdDead = dif < macdv and dif[1] >= macdv[1];   { MACD 死亡交叉：DIF 跌破 MACD 線 }

buySig  = kdjUp and macdUp and dif < 0 and macdv < 0;
sellSig = kdDn and macdDead and dif > 0 and macdv > 0;

{ ---- 狀態機：訊號當根收盤決定，下一根開盤成交 ---- }
if inTrade = false then begin
	if buySig then begin
		inTrade = true;
		barsIn = 0;
	end;
end
else begin
	barsIn = barsIn + 1;
	if barsIn = 1 then
		entryPx = Open;  { 進場價 = 買進訊號隔天開盤（等同回測中的 EntryPrice） }
	if sellSig or Close < entryPx * (1 - StopPct / 100) then
		inTrade = false;
end;

{ ---- 下單：0 / 100% 部位 ---- }
if inTrade and MarketPosition = 0 then begin
	shs = IntPortion((Capital + NetProfit) / Close);
	if shs > 0 then
		Buy ("LE") shs shares next bar at market;
end;

if inTrade = false and MarketPosition = 1 then
	Sell ("LX") next bar at market;
