{ =====================================================================
  trend_sma_half ── 均線趨勢減碼（上升趨勢 100%、下降趨勢 50%，只做多）
  ---------------------------------------------------------------------
  規則（與 Python 版 strategies/trend/strategy.py 的 sma_half() 相同）：
    MA  = MALen 日簡單均線
    Sig = 近 VolLen 日「日對數報酬」的樣本標準差 × √21（約一個月的波動度）
    Z   = (收盤 ÷ MA − 1) ÷ Sig
    Z > +BandK → 上升趨勢；Z < −BandK → 下降趨勢；中間則維持原判定（遲滯帶）
    部位 = 50% 核心持股（一直持有）＋ 50% 趨勢部位（只在上升趨勢時持有）

  輸入參數：
    MALen   均線長度，預設 126（約半年）
    VolLen  波動度估計長度，預設 60
    BandK   遲滯帶寬（單位：一個月波動度），預設 0.5
    LotSize 下單單位股數：1 = 零股，1000 = 整張

  使用前請務必設定（Strategy Properties）：
    1. 日線、還原權值（除權息調整）價格。
    2. Commission：買賣各 0.1425%；證交稅：賣出 0.3%。若無法只對賣出收稅，
       可用「雙邊各 0.2925%」近似（來回 0.585%，與 Python 回測相同）。
    3. Slippage：依實際情況設定（Python 回測未計滑價，以隔日開盤價成交）。
    4. Position Limits：勾選「Allow up to 2 entry orders in the same direction
       as the currently held position ─ when the order is generated by a
       different entry order」。本程式用兩個不同名稱的進場單（Core、Trend）
       各買半倉；同名進場單在持有中重複送出時 MultiCharts 會自動忽略。
    5. Initial Capital 例如 1,000,000；MaxBarsBack 至少 130（或 Auto-detect）。

  與 Python 版的差異（近似）：
    Python 版是「目標曝險 0.5 / 1.0」，減碼時把部位調回剛好 50% 權益；
    本程式減碼時是賣出當初「Trend」那一筆的股數，加碼時以當時權益的一半買進，
    部位大小會略有不同，但加減碼的時點相同。
  ===================================================================== }

inputs:
    MALen(126),
    VolLen(60),
    BandK(0.5),
    LotSize(1);

vars:
    TrendMA(0),
    LogRet(0),
    MonVol(0),
    ZScore(0),
    TrendUp(0),
    Eq(0),
    HalfQty(0);

TrendMA = Average(Close, MALen);
if Close[1] > 0 then
    LogRet = Log(Close / Close[1]);
MonVol = StandardDev(LogRet, VolLen, 2) * SquareRoot(21);   { 2 = 樣本標準差，與 pandas 相同 }

if MonVol > 0 and TrendMA > 0 then begin
    ZScore = (Close / TrendMA - 1) / MonVol;
    if TrendUp = 0 and ZScore > BandK then
        TrendUp = 1
    else if TrendUp = 1 and ZScore < -BandK then
        TrendUp = 0;
end;

Eq = InitialCapital + NetProfit + OpenPositionProfit;
HalfQty = IntPortion(0.5 * Eq / Close / LotSize) * LotSize;

{ 核心半倉：一開始就買進並一直持有 }
if HalfQty > 0 then
    Buy ("Core") HalfQty shares next bar at market;

{ 趨勢半倉：上升趨勢加碼、下降趨勢減碼 }
if TrendUp = 1 then begin
    if HalfQty > 0 then
        Buy ("Trend") HalfQty shares next bar at market;
end
else
    Sell ("TrendX") from entry ("Trend") next bar at market;
