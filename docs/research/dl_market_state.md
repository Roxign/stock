# dl_market_state：大盤狀態曝險模型（E3）研究紀錄

> 一句話結論：用 39 個大盤層級特徵（價格、廣度、離散度／相關性、三大法人、融資、借券、put/call、外資台指期／選擇權未平倉、全球市場）訓練一個「決定 50 檔共同曝險 g_t」的小模型，**在樣本內 walk-forward、purged 交叉驗證與樣本外都沒有勝過買進持有**，也沒有勝過同平均曝險的 B1／B3 對照。發布的 MLP 在資料夠多之後幾乎學成「一直持有」：2020 年起 g_t 恆為 100%，所以樣本外與買進持有完全相同。這是一個誠實的負面結果，不是可以拿來增加報酬的策略。

## 1. 假設

先前 `kdj_macd_dl` 的 RESEARCH.md 發現：DL 模型的「改善」大多來自「大盤狀態＋多持有」，而不是個股選擇。E3（`research/dl_literature.md` §6 E3）把這件事做成明確的大盤模型：

- 一個模型、每天一組輸入（大盤層級），輸出所有股票共用的曝險 g_t ∈ [0, 1]，部位 w_i = g_t。
- 假設：外資現貨／期貨／選擇權部位、融資、put/call 與美股／半導體等全球脈絡，能預測未來 20～60 日等權大盤的報酬與回撤，因此能在大跌前降低曝險。
- 主要風險（文獻已警告）：有效樣本極少（2010–2020 只有約 5～10 次大回撤），Welch & Goyal 指出大多數大盤預測變數在樣本外輸給歷史平均。

**缺資料的處理：** 每個訓練窗的標準化（平均、標準差）只用該窗的訓練樣本計算，裁切在 ±5；缺值設為 0（＝訓練平均）。外資期貨／選擇權在 2018-06 之前全部缺值：2012–2018 年的模型在訓練時這 4 欄恆為 0，等於不用；2019 年起的模型才看得到部分有值的樣本，`has_fut` 讓模型分辨「真的接近平均」與「沒有資料」。

**標籤：** 等權 50 檔「開盤到開盤」指數，從 t+1 開盤（成交點）到 H 根後開盤的 log 報酬 R_H 與期間最大回撤 DD_H（H = 20、60）。標籤在 t+1+H 才完全已知，walk-forward 只用「在訓練截止日之前已知」的樣本。

## 4. 模型與部位映射

- **線性／樹模型（對照）：** ridge（α = 0.1/1）、L2 logistic（C = 0.01，標籤 R>0，再用一個斜率把機率換回期望報酬）、HistGradientBoosting（depth 2、150 棵、lr 0.03、葉節點至少 200 樣本）。預測報酬 μ̂ 經 Campbell–Thompson 映射：w = clip((μ̄ + s(μ̂ − μ̄)) / (γ·m₂), 0, 1)，γ = 3；`const` 用無條件 E[R²]，`cond` 用 H·σ²₆₀ + μ̄²（條件波動）。
- **MLP（發布）：** 39 → 16（tanh）→ 1（sigmoid），直接輸出曝險 g；損失是二次效用的負值 −mean(g·R − γ/2·g²·R²)（R 為未來 20 日簡單報酬，γ = 3），所以不用另外映射。AdamW（lr 3e-3、weight decay 1e-2）、輸入高斯雜訊 0.1、batch 256、最多 150 epoch。**prior 初始化：** 最後一層權重縮小 10 倍、偏差設成訓練集的無條件最佳曝險 g₀ = E[R]/(γE[R²])，所以「什麼都沒學到」的網路就是常數曝險（向無條件平均收縮）。**早停：** 每個訓練窗最後 252 根作為驗證尾段（之前 H+5 根剔除），找最佳 epoch 數後用全部樣本重訓相同 epoch 數。5 個種子取平均。每個 MLP 657 個參數，5 個合計 **3,285 個可訓練參數**（遠低於 5 萬）。
- **walk-forward：** 每年 1 月 1 日重訓（擴張窗，訓練樣本從 2008-07 起），第一個模型 2012 年（用 2008-07～2011 已知的標籤）。**2010–2011 沒有模型，曝險固定 100%（文件化的 fallback）。**
- **部位映射：** raw g → EMA(10) → floor + (1 − floor)·g（floor = 0.5）→ 0.25 為一格量化，且要偏離目前值 ≥ 0.75 格才換（遲滯帶），所以部位只會是 50%／75%／100%，換手低。所有股票 w_i = g_t（不是橫斷面策略，所以沒有 `weights`；投組計分板用等額 1/50 槽位）。
- **計算時間：** `positions()` 全部 50 檔約 50 秒（CPU、torch 2 threads）。

### 5.4 凍結的設計與理由

選擇 v5（MLP16、H = 20、γ = 3、prior 初始化、全部 39 個輸入含外資期貨／選擇權、EMA 10、floor 0.5、0.25 格遲滯量化、5 個種子），理由：(1) 在 v2 之後的「不外插」特徵版本中，它與 v4 的 IS Sharpe 最高（0.43～0.44）且 dev CV（0.505）不低於任何非平凡的對手（logit 0.516 的差距遠小於換種子造成的 ±0.05）；(2) 它涵蓋 E3 指定的全部輸入，缺資料有明確處理；(3) prior 初始化讓模型在沒有訊號時退回常數曝險，是本專案最不容易過度配適的 DL 版本。**沒有任何一個樣本內設定勝過買進持有（IS 0.48、dev CV 0.498）**，凍結時已預期它不會在樣本外勝出。凍結後只跑一次 `--periods is,oos`。

## 7. 弱點與誠實結論

1. **沒有勝過買進持有，也沒有勝過對照組。** IS 0.43 vs B&H 0.48、B1 0.47；OOS 與 B&H 相同（因為 2020 年後一直 100% 持有）；8 折 purged CV 平均 0.640 vs B&H 0.654。同輸入的 logistic、ridge、GBDT 也都沒有勝出（IS 0.40～0.44，OOS 0.99～1.01，CV 0.58～0.62）。
2. **MLP 學到的是「持有」。** prior 初始化 + 早停 + 效用損失下，資料越多網路越接近常數最佳曝險（10 年上漲市場的 E[R]/(γE[R²]) 接近或超過 1）。2012–2014 的降曝險來自包含 2008 年崩盤的短訓練窗，事後看只是少賺。若不用 prior 初始化或 floor，模型平均曝險 60%～80%，在這段多頭期間的代價更大（v2 表）。
3. **有效樣本太少。** 20 日標籤在 2008–2020 只有約 160 個不重疊的樣本、5～10 次大回撤；39 個特徵（含 4 個 2018-06 才開始的欄位）對它們來說太多，任何非平凡的訊號都會被換種子（dev CV 0.51 → 0.61）或特徵版本（v1 → v2）的雜訊淹沒。外資期貨／選擇權欄位在樣本內只出現約 2.5 年，無法評估其價值。
4. **樣本內研究的試驗次數多（超過 100 筆，見 trials.jsonl）**，若真有某個設定略勝，也應以 Deflated Sharpe 打折；本研究沒有任何設定接近顯著。
5. **時點與資料：** 美股用前一晚收盤、法人／融資用當晚公布值；FinMind 成交值有缺口（以因果比例補值）。這些都已過截斷前視檢查，但即時使用時要確定外部資料在隔天開盤前已更新，否則 export_signals 會沿用舊值。
6. **如果要繼續：** 大盤層級的時機選擇在這個市場、這個期間沒有可用的訊號；與其加更多特徵，不如接受「多持有」並把力氣放在個股層級（E1／E2）或成本與再平衡規則上。把本模型的 g_t 當作其他策略的「風險開關」也不建議——它在 2020 年後從未關閉，且回撤 AUC 接近 0.5。
