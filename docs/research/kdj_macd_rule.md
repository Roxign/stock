# KDJ + MACD 規則型策略研究筆記

研究方向：以 KDJ（K、D 與 J 線）與 MACD 為核心決策的規則型策略（只做多），標的為元大台灣50（0050）目前 50 檔成分股，
比較基準為「買進持有」與「定期定額」。本方向共做了兩輪：

- **第二輪（本節 A，目前發布的版本）**：依需求改用 **KDJ**（J = 3K − 2D），並另外測試台灣常看的均線（5/10/20/60/120/240 日）。
- 第一輪（下方 B 節，保留作為歷史紀錄）：只用 KD 與 MACD。第一輪的 `kd_macd_rule_*` 策略已移除。

---

## A. 第二輪：KDJ + MACD（＋均線測試）

### A0. 結論摘要

- **J 線在「日資料的短線統計」上確實比 K 線多一點資訊，但放進扣成本的實際策略後，幾乎沒有差別。**
  - J < 0 的日子隔天超額報酬年化 +34%，比 K < 20 的 +27% 強；K < 20 但 J ≥ 0（跌勢已放緩）只剩 +16%。
  - J < 0 連續 3 天（且 MACD 偏空）之後 5 天平均超額 +1.09%，K < 20 黃金交叉只有 +0.34%。
  - 但這些效果集中在 1～10 天內，一次來回成本 0.585% 就吃掉大半；J > 100 的「超買」效果更只有 1～5 天，20 天後股價平均還在漲。
- **J 與 K、D 的交叉和 KD 交叉是同一件事**：J − D = 3(K − D)、J − K = 2(K − D)，所以「J 穿越 K」「J 穿越 D」「K 穿越 D」必定發生在同一根 K 棒。實務上說的「J 線領先交叉」在數學上不存在。
- 把 J 的規則直接換掉 KD 規則（J < 0 買、J > 100 賣）**比 KD 版更差**：J 太靈敏，一反彈就碰到 100，賣在起漲初段。
- 主策略 **`kdj_macd_rule_trend_bounce`**：MACD 訊號線 > 0 持有（趨勢腿）；訊號線 ≤ 0 時，J < 0 且 D < 20（三線超賣）進場搶反彈，J 連續 3 天 > 100 且 D > 80（持續超買）才出場。
  - 樣本內：CAGR 9.0% / MDD −45.0% / Sharpe 0.49（買進持有 9.6% / −46.1% / 0.49）。
  - 樣本外（只跑一次）：CAGR 29.3% / MDD −44.1% / Sharpe 1.04（買進持有 35.7% / −45.5% / 1.10、定期定額 25.3%）。
- **KD vs KDJ 判決**：樣本內，同一架構下 KDJ 版與 KD 版逐檔 Sharpe 差的中位數 +0.03，90% 信賴區間 [−0.02, +0.07]，**在雜訊範圍內**。
  樣本外 KDJ 版較好（Sharpe 1.04 vs 0.98，74% 的股票較高），但主要原因是反彈單抱得比較久、在大多頭中持股率比較高（89% vs 86%），不是擇時變準。
- **均線（MA）沒有幫助**：價格相對月線/季線/年線的位置、多頭排列、價格穿越月線/季線，對之後報酬都沒有顯著預測力；
  拿來當濾網或進出場條件，樣本內全部持平或變差，因此發布的策略**沒有使用均線**。唯一有點用的是「月線 > 季線」可以取代 MACD 訊號線當趨勢腿（結果幾乎一樣），代表兩者衡量的是同一種中期動能。
- 另發布 **`kdj_macd_rule_classic_zone`**（J < 0 且 MACD 柱狀體上升買、J > 100 且柱狀體下降賣）作為網路常見口訣的對照組：勝率高、報酬遠低於買進持有。
- 誠實的總結和第一輪相同：**KDJ/MACD/均線規則最多做到與買進持有相近的風險報酬，沒有找到能穩定打敗買進持有的版本。**

從文獻與實務得到的 KDJ 假說：
- H7：J < 0 / J > 100 是比 K < 20 / K > 80 更強的超賣/超買訊號（口訣）。
- H8：J 線穿越 K、D 是比 KD 交叉更早的買賣點（實務說法）。
- H9：J 連續多天 < 0（> 100）比單日更可靠（三線超賣/超買說法）。
- H10：J 背離 + J 拐頭能提高反轉訊號品質。
- H11：MACD 定方向、KDJ 找買點（「共振」）。
- H12：均線是多空分界（站上季線/年線才做多、多頭排列 5 > 10 > 20 > 60、價格穿越月線/季線進出）。

### A2. 研究設定（與第一輪的差異）

- 資料清理已更新（減資/分割還原、興櫃資料剔除），基準數字因此略有變動：樣本內買進持有 CAGR 9.6% / MDD −46.1% / **Sharpe 0.49**，
  定期定額 5.8%；第一輪的 KD 主策略在新資料上為 8.7% / −47.9% / 0.48（第一輪報告是 8.9% / −47.9% / 0.51）。
- 指標：`tw_kdj`（9,3,3、1/3 平滑、初值 50、J = 3K − 2D）、MACD 12,26,9、`sma` 均線 5/10/20/60/120/240 日。
- 0/1 部位的向量化回測與 `stocklab.backtest.simulate` 逐檔比對（CAGR、MDD、Sharpe、持股比、調整數、交易數、勝率），最大誤差 1.5e-14，所以下表的樣本內數字與 `evaluate.py` 一致。
- 事件研究的 t 值改為**以月份群聚（clustered by month）**計算：同一個月很多股票同時出現訊號（例如大跌時一起超賣），一般 t 值會高估顯著性。
- 開發與調參**只用樣本內**（2010–2020）。樣本外在參數凍結後只跑一次。這一輪大約測試了 400 組規則/參數。

解讀：
- **H7 部分成立**：J < 0 是比 K < 20 更「純」的超賣狀態（K < 20 中跌勢已放緩、J 已回到 0 以上的那一段報酬只剩一半）；J ≥ 100 也是比 K ≥ 80 更強的短線過熱。
  但兩邊的效果都集中在 1～10 天，J > 100 的負報酬在 20 天後就消失、甚至轉正 —— **J > 100 是短線過熱，不是好的賣點**（和第一輪「KD 高檔死叉賣太早」一致）。
- **H8 不成立（數學上）**：J − D = 3(K − D)、J − K = 2(K − D)，三線交叉必定同一天發生；回測也驗證「J > K 持有」「J > D 持有」「K > D 持有」三者完全相同（CAGR −9.9%、Sharpe −0.48）。
- **H9 成立**：「J 連續 3 天 < 0」與「J 跌破 −10」是所有超賣事件中最強的（5 天 +0.7%，t ≈ 3.5）；在 MACD 偏空時更強（+1.09%）。
- 等「確認」反而變差：J 站回 0、超賣後的 KD 金叉，之後報酬都是 0 或負的 —— 反彈在確認之前就已經發生。
- **H10 不成立**：J 背離沒有預測力（第一輪的 DIF 背離也一樣）。
- 最強的組合狀態是「**MACD 多頭中的 J < 0**」（年化 +51%，t = 5.7），但這時趨勢腿本來就持有；空頭中的 J < 0 平均效果弱得多（+13%），只有「連續 3 天」這種深度超賣才有明顯的 5 天反彈。

### A4. KDJ 規則實驗（樣本內，49 檔中位數）

表格欄位：CAGR / MDD / Sharpe / 持股比 / 交易數 / 勝率 /「勝B&H」= CAGR 勝過買進持有的股票比例 /「Sh勝」= Sharpe 勝過買進持有的比例。

- 單用 J 的口訣比 KD 版更差：J 一反彈就超過 100，交易次數多 5 倍，賣在起漲初段。
- 唯一不錯的單一 KDJ 規則是「三線超賣/超買」：它的**出場條件很嚴格**（K、D、J 都要在高檔而且 J 連續 3 天 > 100），所以抱得久，持股比 50%。這提示 J 的用法應該是「深度超賣才進、持續超買才出」。

#### A4.2 KD vs KDJ：同一個「MACD 趨勢腿 + 反彈腿」架構

趨勢腿固定為 MACD 訊號線 > 0；反彈腿只在訊號線 ≤ 0 時開啟，只替換進場/出場條件（樣本內 Sharpe，括號為 CAGR）：

| 反彈進場 ＼ 反彈出場 | K > 80 死叉（KD） | J > 100（單日） | J 連續 3 天 > 100 且 D > 80 |
|---|---|---|---|
| K < 20 金叉（KD） | 0.50（8.6%） | 0.38（5.3%） | 0.53（8.5%） |
| J < 0 | 0.49（8.9%） | 0.41（6.4%） | 0.50（8.9%） |
| **J < 0 且 D < 20（三線超賣）** | 0.49（7.8%） | 0.41（6.4%） | **0.49（9.0%）← 發布** |

參考：只有趨勢腿（訊號線 > 0）為 5.2% / −38.4% / 0.42；第一輪原版（KD 反彈單在任何趨勢下都可開啟）在新資料上為 8.7% / −47.9% / 0.48。

- **進場**換成 J 沒有差別（每一欄的上下差距都 ≤ 0.04）。
- **出場**用單日 J > 100 明顯變差（−0.08～−0.12）；改成「J 連續 3 天 > 100 且 D > 80」與 KD 高檔死叉差不多或略好。
- 結論：在能扣成本、能長抱的架構裡，J 的作用頂多和 K 相當。

#### A4.3 讓 J 管理趨勢腿（H11 的各種寫法）

### A7. 已知弱點與注意事項

1. **沒有真正的超額報酬**：樣本內與買進持有打平、樣本外落後。J 線的短線資訊（1～10 天）被 0.585% 的來回成本吃掉，能利用的只有持有期較長的部分。
2. **J 進場較早，急跌時更早接刀**：2015、2020 急跌期間比 KD 版多虧 5～7 個百分點。反彈腿在長空頭裡也可能抱著下跌，直到出現持續超買。
3. **樣本外比 KD 版好，主要是持股比較高**，在大多頭中這是優點，不代表擇時能力更好。
4. **單一參數組套用 50 檔**，低波動的金融股與高波動電子股的 J 值分布不同（金融股較少出現 J < 0），但分股調參的過度擬合風險更大，所以沒有做。
5. **倖存者偏差**：成分股是 2026 年 10 月的名單（事後贏家），買進持有基準因此特別強。
6. **資料**：回測用還原權值價格，未計滑價；真實交易若用未還原價，除權息缺口會影響 KDJ/MACD。年線需要 240 根資料，2010 年的均線測試只有部分期間有效。
7. **多重測試**：本輪約測試 400 組規則/參數（第一輪約 350 組），即使最後選的是口訣值，「挑最好的」仍有選擇偏誤。

- 交易成本請在 Strategy Properties 設定（手續費 0.1425%、賣出證交稅 0.3%、滑價）。
- `evaluate.py --family kdj_macd_rule --lookahead`：兩個策略在 2014-06-30、2018-03-30、2022-09-30 三個截斷點皆 **0 根 K 棒不同（0.000%）**。50 檔部位計算約 0.1 秒。

## B. 第一輪：KD + MACD（歷史紀錄）

> 以下是第一輪（只用 KD）的研究筆記，原樣保留。當時的策略 `kd_macd_rule_trend_bounce`、`kd_macd_rule_classic_zone` 已移除；
> 數字是當時的資料清理版本，與 A 節略有差異（例如買進持有樣本內 Sharpe 當時為 0.51，現為 0.49）。
研究方向：以 KD 與 MACD 為核心決策的規則型策略（只做多），標的為元大台灣50（0050）目前 50 檔成分股，
比較基準為「買進持有」與「定期定額」。

### B0. 結論摘要

- **單獨使用 KD 或 MACD 的經典交叉訊號，在台灣大型股扣除交易成本後幾乎都輸給買進持有**，很多甚至是負報酬：
  KD 黃金交叉買、死亡交叉賣的樣本內 CAGR 中位數是 −10.3%，MACD 黃金/死亡交叉是 −1.7%。
- 事件研究找到兩個有用的現象：
  1. **短期反轉**：KD 進入超賣區（K < 20）之後幾天報酬明顯偏高；K > D 的日子隔天報酬反而偏低。
     KD 高檔（K > 80）死亡交叉之後 20～40 天平均還在漲 —— 也就是說「KD 高檔死叉賣出」通常賣太早。
  2. **中期趨勢**：MACD 訊號線（DIF 的 9 日 EMA）跌破零軸後 20～40 天平均明顯落後，是較可靠的「出場」訊號。
- 依此設計的主策略 **`kd_macd_rule_trend_bounce`**（MACD 訊號線 > 0 持有，另加 KD 超賣黃金交叉搶反彈）
  樣本內 Sharpe 與買進持有相同（0.51 vs 0.51），CAGR 略低（8.9% vs 9.6%），47% 的股票 Sharpe 勝過買進持有。
  樣本外（2021–2026 大多頭）落後買進持有（CAGR 29.0% vs 35.7%，Sharpe 0.98 vs 1.10）。
- 另外發布 **`kd_macd_rule_classic_zone`**（KD 低檔金叉 + MACD 柱狀體確認、高檔死叉出場）作為台灣常見教科書規則的對照組：
  勝率高（67%～80%），但報酬遠低於買進持有。
- 誠實的總結：在 2010–2026 的台灣權值股上，**KD/MACD 規則最多能做到「與買進持有相近的風險報酬、偶爾少跌一點」，
  沒有找到能穩定打敗買進持有的版本**。這和近年學術研究的結論一致。

從文獻得到的研究假說：
- H1：純 KD / MACD 交叉在個股日線上扣成本後不會打敗買進持有（文獻與實務回測一致）。
- H2：在超賣/超買區內的 KD 交叉比任意交叉好（實務共識）。
- H3：MACD 零軸位置（趨勢）比訊號線交叉（短期動能）更適合當濾網（Chong & Ng 的 MACD(12,26,0)、Elder 的長線濾網）。
- H4：一個指標當觸發、另一個當確認/濾網，可改善單一指標（實務共識、Chio 2022）。
- H5：背離（Lane）能提高反轉訊號品質。
- H6：KD 高檔鈍化代表強勢，不該在 KD 高檔死叉時賣出。

### B2. 研究設定

- 資料：`stocklab.data.load_all()`，還原權值日線 2010-01 ～ 2026-10-02。
- 引擎：`stocklab.backtest`，第 t 根收盤決定目標部位、第 t+1 根開盤成交；買 0.1425%、賣 0.1425% + 0.3% 證交稅；
  每個期間各自從 100 萬元開始，前 60 根為暖機。
- 開發與調參**只用樣本內**（2010–2020）；樣本外（2021-01-01 ～ 2026-10-02）只在最後跑一次。
- 為了快速掃描參數，我寫了一個 0/1 部位的向量化回測，與 `stocklab.backtest.simulate` 逐檔比對 CAGR、MDD、Sharpe、
  持有率、交易數、勝率，誤差 < 1e-14，因此以下樣本內數字與 `evaluate.py` 完全一致。
- 指標：KD 9,3,3（台灣 1/3 平滑）、MACD 12,26,9（DIF、訊號線 = DIF 的 EMA9、柱狀體 OSC = DIF − 訊號線）。
- 表格中「CAGR / MDD / Sharpe」皆為 50 檔（樣本內 49 檔，7769 無資料）的中位數；「勝B&H」是 CAGR 勝過買進持有的股票比例，
  「Sh勝」是 Sharpe 勝過買進持有的比例。
- 樣本內基準：買進持有 CAGR 9.6% / MDD −46.1% / Sharpe 0.51；定期定額 CAGR 5.8%。

#### B3.2 為什麼？—— 狀態與事件研究

把 49 檔樣本內每天依指標狀態分組，看「隔天開盤到下一天開盤」的報酬（扣除各股平均漂移後年化）：

| 狀態 | 時間占比 | 年化超額報酬 |
|---|---|---|
| K < 20 | 11% | **+28.1%** |
| 20 ≤ K < 50 | 36% | −1.4% |
| 50 ≤ K < 80 | 39% | −3.3% |
| K ≥ 80 | 14% | −8.9% |
| 訊號線 > 0 且 K < D | 32% | +11.0% |
| 訊號線 > 0 且 K > D | 27% | −6.3% |
| 訊號線 < 0 且 K < D | 18% | +1.6% |
| 訊號線 < 0 且 K > D | 24% | −8.9% |

事件發生後（隔天開盤進場）的平均累積超額報酬（基點，bp）：

| 事件 | 次數 | +5 天 | +20 天 | +40 天 |
|---|---|---|---|---|
| K 跌破 10 | 963 | +57 | +81 | +143 |
| K < 20 時 KD 金叉 | 973 | +27 | +11 | +72 |
| K < 30 時 KD 金叉（含 K < 20） | 2719 | −18 | −35 | −9 |
| K > 80 時 KD 死叉 | 1369 | +12 | +37 | +89 |
| MACD 金叉（DIF 在零軸下） | 2581 | −26 | −25 | −20 |
| 訊號線向上穿越零軸 | 1407 | +25 | +16 | −4 |
| 訊號線向下跌破零軸 | 1434 | −31 | **−84**（t = −3.8） | −109 |
| DIF 向下跌破零軸 | 2055 | +13 | −47 | −80 |

解讀：
- 日線上 KD 主要反映**短期反轉**：越超賣越容易反彈，K > D 的日子（剛金叉、正在漲）隔天反而偏弱。
  所以「KD 金叉追進、死叉殺出」是在反方向交易，扣成本後必然虧損。
- **H6 成立**：K > 80 的死叉之後 20～40 天平均仍上漲，KD 高檔死叉不是好的賣點（呼應「高檔鈍化」的實務說法）。
- **MACD 訊號線跌破零軸**是全部事件中最強的負面訊號；向上穿越零軸則只有微弱的正面效果。
- 這些效果都不大（個股每日波動約 2%），短期效果又遠小於一次來回 0.585% 的成本 —— 能利用的只有持有期較長的部分。

| **訊號線 > 0 持有 OR KD 超賣反彈（K<20 金叉 → K>80 死叉）（發布：trend_bounce）** | **8.9%** | −47.9% | **0.51** | 85% | **41%** | **47%** |

- 「KD 觸發 + MACD 確認」的各種組合（H4 的直覺版本）都沒有改善，MACD 柱狀體確認甚至讓純 KD 低買高賣變差（0.37 → 0.35）。
- 有效的組合方式反而是**讓兩個指標各做自己擅長的事、用 OR 合併**：MACD 訊號線負責「中期趨勢在就抱」，
  KD 超賣金叉負責「趨勢不在時，跌深了先撿回來」。兩條腿的報酬來源不同（趨勢 vs. 反轉），合併後持有率回到 85%，
  避開了單純趨勢濾網「錯過反彈」的最大缺點。
- 逢低才進場（等 KD 回檔）反而變差：沒有回檔的強勢段直接錯過。

#### B3.6 子期間穩健性（樣本內）

| 期間 | 主策略 CAGR / MDD / Sharpe | 買進持有 CAGR / MDD / Sharpe | Sharpe 勝 B&H |
|---|---|---|---|
| 2010–2015（盤整、2011 與 2015 空頭） | 4.9% / −39.3% / 0.32 | 4.0% / −43.3% / 0.29 | 40% |
| 2016–2020（多頭） | 13.2% / −38.4% / 0.66 | 15.2% / −39.3% / 0.74 | 45% |

逐年看（主策略減買進持有的年報酬，個股中位數）：2011 年 0.0%、2015 年 +2.5%，其餘年份 0 ～ −4.8%。
**典型的擇時策略輪廓：盤整/空頭年小贏、多頭年小輸。**

### B4. 最終發布的策略與選擇理由

#### `kd_macd_rule_trend_bounce`（MACD趨勢＋KD超賣反彈）—— 主策略
- 規則：MACD(12,26,9) 訊號線 > 0 持有；另外 K < 20 的 KD 金叉開啟反彈單，K > 80 的 KD 死叉關閉反彈單；任一成立就持有。
- 選擇理由：所有測試過的 KD/MACD 規則中樣本內 Sharpe 最高的一群，而且用的全是教科書預設參數；
  鄰近參數平坦（超賣門檻除外）；邏輯有事件研究支持（趨勢腿用 MACD 最可靠的出場訊號，反彈腿用 KD 的短期反轉）。

#### `kd_macd_rule_classic_zone`（KD低檔金叉＋MACD柱確認，傳統對照）
- 規則：K < 20 的 KD 金叉且 MACD 柱狀體上升 → 買；K > 80 的 KD 死叉且柱狀體下降 → 賣。
- 選擇理由：這是台灣最常被推薦的 KD + MACD 搭配法。放上網站讓使用者在每一檔股票上直接看到它「勝率高、報酬低」的特性，
  與主策略、基準對照。**不建議實際使用。**

兩者都是 0 / 100% 部位，MultiCharts 版本與 Python 邏輯一致（見 B7）。

### B6. 已知弱點與注意事項

1. **沒有真正的超額報酬**：樣本內與買進持有打平、樣本外落後。KD/MACD 在台灣大型股上的可預測性很小，且多半是短期（數日）效果，被 0.585% 的來回成本吃掉。
2. **超賣門檻敏感**：L = 20 是局部高點，15 / 25 明顯較差。
3. **下檔保護有限**：中期 MACD 濾網對一個月內的急跌（例如 2020 年 3 月，多檔股票的最大回落就發生在這裡）反應太慢；反彈腿在長空頭裡也會反覆接刀。
4. **單一參數組套用 50 檔**：金融、電信等低波動股與高波動電子股的最佳參數可能不同，但分股調參的過度擬合風險更大，所以沒有做。
5. **倖存者偏差**：成分股是 2026 年 10 月的名單（事後贏家），買進持有基準因此特別強；對所有策略都一樣，但會放大「擇時落後」的程度。
6. **資料**：回測用還原權值價格，未計滑價；真實交易若用未還原價，除權息缺口會影響 KD/MACD。
7. 研究期間也嘗試了大量變形（約 350 組），即使最後挑選的是教科書參數，「挑最好的」本身仍有選擇偏誤，樣本外落後正是提醒。
