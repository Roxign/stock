# 均值回歸 / 擺盪指標策略研究筆記

研究範圍：0050 目前 50 檔成分股、日線、只做多。訊號在收盤時計算，**次日開盤成交**；成本為手續費 0.1425%（買賣各一次）加證交稅 0.3%（賣出），來回約 **0.585%**。
所有調參都只用**樣本內 2010–2020**，50 檔共用一組參數。樣本外（2021–2026/10）只在最後跑了一次。
表中數字除非特別說明，都是 50 檔的**中位數**（樣本內 7769 資料不足，n = 49）。

## 2. 假說

- **H1** 經典短線規則（RSI(2)、累積 RSI、雙 7、IBS、布林通道）在台股大型股上**扣成本前**有優勢。
- **H2** 次日開盤才進場會吃掉一部分優勢（反彈先在隔夜發生）。
- **H3** 台灣 0.3% 的證交稅讓持有 3–5 天的策略難以獲利；需要**每筆預期報酬更大**的訊號。
- **H4** 長期多頭濾網（收盤 > 200 日均線）能改善逢低買進。
- **H5** 停損會傷害均值回歸策略。

## 3. 實驗（全部為樣本內 2010–2020）

### 3.1 事件研究：訊號之後次日開盤買進的平均報酬

將 50 檔所有交易日合併計算；報酬 = 第 t+1 天開盤買、第 t+1+h 天開盤賣（未扣成本）。

| RSI(2) < 10 且 > 200MA | 6,241 | 0.27% | 0.56% | 0.70% | 0.84% |

- 但這個超額報酬**和來回成本 0.585% 差不多大**。只有「跌得夠深」的訊號（5 日跌 8%–12% 以上）超額報酬才明顯大於成本。

**H2 不成立**：延後到次日開盤幾乎沒有損失（超賣後的隔夜跳空平均 +0.07%，反而低於一般日的 +0.16%）。

| 策略（回測） | 實際成本 CAGR / Sharpe / 每筆平均 | 零成本 CAGR / Sharpe / 每筆平均 |

**H4 部分成立**：短線（1–5 天）規則加上 200 日均線濾網確實較好（RSI(2)<10：Sharpe −0.07 → 0.12）。但跌幅很深的情況剛好相反：在 200 日均線**之下**的深跌，之後 10–20 天的反彈更大（例如 5 日標準化跌幅 < −2.5σ：均線上 h20 超額 +1.3%，均線下 +4.3%）。

### 3.4 為什麼低持有率的策略很難贏買進持有

部分時間持股的策略，Sharpe 約等於「持股期間的 Sharpe × √持有率」。買進持有的 Sharpe 是 0.51；若策略只有 10% 時間持股，持股期間的 Sharpe 要超過 1.6 才追得上。經典規則零成本時持股期間 Sharpe 約 1.6（剛好打平），扣成本後就不夠了。
所以有兩條路：(a) 找**每筆報酬大很多**的訊號（減少成本占比）；(b) **提高持有率**又不稀釋太多效率。

### 3.6 反彈從哪裡來：全市場恐慌 vs. 個股利空

以 50 檔等權平均當作「大盤」，大盤 20 日跌幅 > 8% 視為恐慌期：

| 訊號 | 恐慌期 h20 / h40 | 非恐慌期 h20 / h40 | 基準 h20 / h40 |
|---|---|---|---|
| 20 日跌幅 > 15% | 9.7% / 15.7% (n=1,200) | 1.4% / 4.9% (n=2,227) | 1.2% / 2.4% |
| RSI(14) < 25 | 11.1% / 15.7% (n=497) | 0.9% / 3.2% (n=811) | 同上 |
| 5 日跌幅 > 10% | 11.6% / 17.9% (n=629) | 1.7% / 4.3% (n=1,335) | 同上 |

**這是本研究最重要的發現**：深跌後的反彈幾乎全部發生在**全市場恐慌**（2011、2015、2018、2020 等）之後；個股自己的急跌，之後的報酬和平常差不多。恐慌事件只有少數幾次，所以有效樣本其實很小。

### 3.7 停損（H5）

|---|---:|---:|---:|---:|---:|---:|---:|
| RSI(14)<25 → >70 或 60 根 | **0.44** | | 0.33 | | 0.44 | 0.34 | 0.40 |
| 5 日跌 >10% → >10MA | **0.34** | 0.24 | 0.28 | | 0.32 | | |
| RSI(5)<20 → RSI(14)>70 | **0.44** | | | 0.42 | | 0.38 | 0.36 |

**H5 成立**：沒有任何停損設定改善 Sharpe，與 Kaminski & Lo 一致。最終版本都不設停損。

### 3.8 其他嘗試（沒有採用）

- **確認進場**（超賣後等收盤突破前一日高點、或站上 5 日均線）：Sharpe 0.40–0.42，沒有比直接進場好。
- **多頭中逢低買、改用不同出場**（RSI(2)<10 且 > 200MA）：出場用 20 日新高 0.25、10 日新高 0.23、固定 20 天 0.20、跌破 200MA 0.35、RSI(14)>70 0.45（但持有率已達 72%）。
- **超買放空的反面（超買就賣）**：RSI(14) > 70/75/80 之後的報酬，合併平均略**高於**基準，但只有約 30–50% 的股票如此 → 超買不是可靠的賣出理由，只有在「之後還能在拉回時買回」時才不會太吃虧。
- **用報酬自我相關判斷「均值回歸期」**：看起來有效，但其實只是挑到崩盤期，沒有採用。

## 4. 最終發佈的版本

| id | 規則 | 為什麼選 |
|---|---|---|
| `mean_reversion_combo` 超跌反彈組合 | A：RSI(14) < 25 買，RSI(14) > 70 或 60 根後賣；B：5 日跌 > 10% 買，收盤站上 10MA 賣；任一持有就持有 | 低持有率版本中 Sharpe 最高，最大回撤約買進持有的一半；兩個不同週期的子系統互補 |
| `mean_reversion_swing` 拉回買進・過熱賣出 | RSI(2) < 10 買，RSI(14) > 75 賣 | 高持有率版本，唯一在樣本內 Sharpe 略高於買進持有的設計 |
| `mean_reversion_rsi2_classic` Connors RSI(2) 經典對照 | > 200MA 且 RSI(2) < 5 買，收盤 > 5MA 賣 | 未調參的教科書版本，讓使用者在網站上直接看到「為什麼經典短線均值回歸在台股不可行」 |

三個版本都通過前視偏差檢查（3 個截斷日，**0% 的 K 棒不同**），50 檔計算部位各約 0.1 秒。
另外用 Python 模擬了 PowerLanguage 的 RSI（含 MultiCharts 的起始值算法）與狀態機：組合與波段版本和 Python 完全一致；經典版 166,072 根中有 10 根不同，都是收盤價剛好等於 5 日均線的浮點數誤差。

**解讀**

- 樣本外是強勢多頭，三個版本的 CAGR 都輸買進持有。
- 超跌反彈組合的**絕對表現和樣本內差不多**（Sharpe 0.49 vs 0.47，MDD −27% vs −26%），報酬主要來自 2025 年 4 月的全市場急跌反彈，再次印證 3.6 節的發現。但買進持有的 Sharpe 從 0.51 跳到 1.10，所以相對排名很差。
- 拉回買進・過熱賣出跟得上大部分漲勢，Sharpe 1.00 接近買進持有，但 2022 年空頭反而跌得比買進持有多（RSI(2) 在下跌中不斷給出買點），回撤只少一點。
- 經典 RSI(2) 在樣本內、外都一樣不可行（Sharpe 0.13 → 0.15）。

## 6. 已知弱點

1. **存活者偏差**：股票池是 2026 年的 0050 成分股，等於事後挑出的贏家。「跌深買進」在這種股票池裡特別容易成功；當年跌下去就沒回來的股票不在樣本裡。
2. **有效樣本小**：深跌反彈的報酬集中在少數幾次全市場恐慌，50 檔股票的訊號高度同步，不是 50 個獨立樣本。
3. **大部分時間空手**：超跌反彈組合約 84% 的時間沒有部位，多頭年份必然大幅落後；它的價值在於「低回撤、只在恐慌時出手」，不是提高報酬。
4. **波段版本優勢很小**：與買進持有幾乎同進同出，樣本外 2022 年還多跌了一些。
5. **MultiCharts 的差異**：若使用未還原權息資料，除權息缺口可能觸發「5 日跌 > 10%」的假訊號（高殖利率股特別要注意）；RSI 起始值不同，需載入足夠歷史；本框架在每個期間開始時若前一根已是持有訊號，會在第一天開盤直接買進，MultiCharts 則要等新訊號。
6. **只用日線、次日開盤成交**：沒有測試收盤前下單（MOC）或盤中訊號；不過 3.2 節顯示收盤進場不會明顯更好。

## 7. 可能的下一步

- **加入大盤恐慌濾網**：3.6 節顯示反彈幾乎只發生在全市場急跌之後。在 MultiCharts 可把加權指數設為 Data2，只在指數也急跌時進場。因為恐慌事件太少，目前沒有據此調參，以免過度配適。
- **投資組合層級**：單一股票的資金大部分時間閒置。若 50 檔共用一筆資金、把錢分給當下訊號最強的幾檔，資金使用率會高很多（但訊號在恐慌時同時出現，需要部位上限）。
- **低成本標的**：ETF（證交稅 0.1%）或有手續費折扣時，短線規則的 Sharpe 會明顯改善（3.11 節）。

## 8. 對共用框架的觀察

- 資料本身沒有發現錯誤。隔夜報酬平均約 +0.16%/日、盤中報酬為負，約 20% 的交易日開盤價等於前一日收盤價；這和台股隔夜效應文獻一致，但若要更確定，可抽查幾檔與證交所官方開盤價比對。
- `evaluate.py` 對基準列會出現 `All-NaN slice` 的 RuntimeWarning（定期定額沒有交易數等欄位），不影響結果。
- 7769 在樣本外只有約 140 根可交易 K 棒，該檔的樣本外指標雜訊很大。
