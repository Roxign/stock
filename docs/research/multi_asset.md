# 多資產配置研究筆記

（2026-10-08；資料至 2026-10-02）

## 動機

`research/diagnosis.md` 的結論：逐檔擇時輸給買進持有，主要是因為持股變少、空手的資金沒有收益，而且 50 檔成分股有倖存者偏差。因此這裡改成：

- 股票部位改用**真正可投資、沒有倖存者偏差的 0050**；
- 不持有股票時，資金改放在通常與股市反向或低相關的資產（美債 20 年 00679B、黃金 00635U），石油 00642U 納入趨勢追蹤；
- 每月調整一次，降低成本；以投資組合層級和 0050 買進持有、0050 定期定額比較。

三個版本（參數皆為文獻常用值，沒有用樣本外調整）：風險平價（不擇時）、趨勢＋風險平價、股債金切換。

## 結果：真實 ETF 資料（投資組合層級：年化報酬 / 最大回撤 / Sharpe）

| 投資組合 | 樣本內 2010–2020 | 樣本外 2021–今 |
|---|---|---|
| 0050 買進持有 | 10.7% / −28.2% / 0.73 | 29.2% / −34.0% / 1.28 |
| 0050 定期定額 | 7.7% / −27.1% / 0.80 | 21.9% / −22.3% / 1.36 |
| **股債金切換** | 4.3% / −28.2% / 0.40 | **26.8% / −21.3% / 1.34** |
| 風險平價（不擇時） | 6.9% / −23.0% / 0.58 | 10.5% / −22.6% / 1.02 |
| 趨勢＋風險平價 | 1.5% / −28.4% / 0.19 | 12.3% / −24.8% / 0.80 |

注意：黃金、石油在 2015 年、美債在 2017 年才上市，所以 2010–2014 年「避險」只能持有現金，樣本內的比較對這些策略不利。

## 延伸測試：用美國 ETF 代理補到 2008 年（僅供參考）

上市前用 GLD／TLT／USO × 美元匯率代理（見 `research/etf_data.md`），格子為 年化 / Sharpe / 最大回撤：

| | 2010–11 | 2012–13 | 2014–15 | 2016–17 | 2018–19 | 2020–21 | 2022–23 | 2024–今 |
|---|---|---|---|---|---|---|---|---|
| 0050 買進持有 | −2.5% / −0.04 / −23% | 12.2% / 0.91 / −15% | 4.5% / 0.38 / −21% | 18.9% / 1.46 / −9% | 12.6% / 0.90 / −18% | 26.4% / 1.26 / −28% | −0.1% / 0.09 / −34% | 58.7% / 1.93 / −27% |
| 股債金切換 | **7.9% / 0.55 / −20%** | −2.0% / −0.12 / −16% | **5.7% / 0.54 / −13%** | 16.7% / 1.39 / −11% | 2.1% / 0.24 / −19% | 17.9% / 0.94 / −28% | **4.8% / 0.46 / −12%** | 47.8% / 1.77 / −21% |
| 風險平價 | **11.3% / 1.13 / −6%** | −1.9% / −0.20 / −12% | −2.1% / −0.23 / −15% | 8.4% / 1.19 / −8% | 8.0% / 1.24 / −8% | 7.9% / 0.72 / −17% | −2.2% / −0.16 / −23% | 21.5% / 1.83 / −10% |

- 股債金切換在三個空頭段（2010–11、2014–15、2022–23）的 Sharpe 都勝過 0050，2022–23 的最大回撤只有 −12%（0050 −34%）；但在多頭段落後，所以整段樣本內仍輸 0050。
- 風險平價在 2010–11 很好，但長期報酬太低（股票只占一部分）。

## 結論

1. 多資產配置的價值是**大幅降低回撤、在空頭時保護資產**，而不是打敗 0050 的報酬。
2. 股債金切換在樣本外的 Sharpe（1.34）略高於 0050 買進持有（1.28），最大回撤從 −34% 降到 −21%，接近定期定額的回撤但報酬更高；這是目前所有策略中最接近「在可投資基準上真正改善」的結果，但在 2012–13、2018–19 這類盤整多頭會落後。
3. 趨勢＋風險平價的換手太高，又常在趨勢反轉時落後一個月，不建議。
