# 台灣融券（放空）規則與回測實作

程式：`stocklab/shortrules.py`（規則與日曆）、`stocklab/backtest.py` 的 `enforce_short_rules`（把策略想要的部位轉成實際做得到的部位）。
策略的部位可以是 −1～+1（負數 = 融券放空）；回測引擎會先套用以下規則，網頁顯示的也是套用規則後的部位。

## 1. 能不能放空（融券標的）

- 以證交所每日「融資融券餘額」報表（FinMind `TaiwanStockMarginPurchaseShortSale`）判斷：某檔股票／ETF 在報表上出現的第一天起，才視為可信用交易。新上市股票通常約 6 個月後才列入（例如 6669 緯穎 2019-10、6446 藥華藥 2023-07、7769 鴻勁 2026-06）。
- 報表「註記」欄：`X` = 停止融券、`O` = 停止融資、`!` = 停止買賣。註記標在報表日，代表**次一營業日**的狀態。

## 2. 停止融券賣出與強制回補（除權息、股東會）

- 除權息、股東常會、現金增資等停止過戶前，交易所會「停止融券賣出」數日，並訂定「融券最後回補日」，未回補者強制回補。
- 實作：註記出現 `X` 的報表日之次一營業日 = 停止融券日。停止融券期間**不得新增空單**；空單在**停止融券的第一天開盤**強制回補。
- 實際的最後回補日通常在停止融券期間內（例如 2330 於 2025/9：註記 9/9–9/12，停券 9/10–9/15，融券餘額 9/11 降為 0），所以我們早一到兩天回補，屬保守做法。
- 這些日期會在約兩週前公告（停資停券預告），回測視為已知，不算偷看未來。

## 3. 平盤以下不得融券賣出

| 期間 | 規定 | 實作 |
|---|---|---|
| 2013/9/22 以前 | 只有台灣50（2005 起）、中型100 與台灣資訊科技指數成分股（2007 起）及 ETF 可在平盤以下放空 | 缺少歷史成分股資料，**一般股票一律視為受限（保守）**；ETF 不受限 |
| 2008/9/22–2009/1/2 | 金融海嘯：連原本豁免的成分股也禁止平盤以下放空（2009/1/5 恢復） | 所有標的受限 |
| 2013/9/23 起 | 全面開放平盤以下融券；但前一日收盤跌停（7%，2015/6/1 起 10%）者，次日不得以低於前一日收盤價放空 | 前一日跌幅 ≥ 6.5%（2015/6 起 ≥ 9.5%）者當日受限 |
| 2015/8/24–2015/9/18 | 股災：平盤以下禁止放空（9/21 解除） | 所有標的受限 |
| 2020/3/20–2020/6/9 | COVID：前一日跌幅達 3.5% 者，次日不得以低於前一日收盤價放空（6/10 取消） | 前一日跌 ≥ 3.5% 者受限 |
| 2022/10/21–2023/2/23 | 同上 3.5% 規定（2023/2/24 取消） | 前一日跌 ≥ 3.5% 者受限 |

「受限」在回測中的意思：當天開盤價低於前一日收盤價時，不能開新空單（已有的空單不受影響）。

## 4. 保證金、維持率、費用

- **融券保證金成數**：一般 90%；2022/10/1–10/11 為 100%、2022/10/12–2023/2/23 為 120%、2025/4/7–5/25 為 130%。
- **擔保維持率**：(融券保證金 + 融券賣出價款) ÷ 股票現值，低於 130% 追繳；回測簡化為：收盤時低於 130% → 下一個開盤強制回補（實務上有兩個營業日可補繳）。以 90% 成數計算，大約是股價比放空價上漲約 46% 時觸發。
- **費用**：放空賣出時付手續費 0.1425% + 證交稅（股票 0.3%、ETF 0.1%、債券 ETF 2017–2026 停徵）+ 融券手續費 0.08%；回補買進時付手續費 0.1425%。融券保證金與價款的利息收入很小，未計入。
- 停止融券期間包含除息日之前，回測的空單不會跨越除權息，因此不需處理股利補償。

## 5. 沒有模擬的部分

- **券源不足、融券限額、標借**：熱門股可能借不到券或被標借，回測假設永遠借得到。
- **借券賣出（SBL）**：法人常用的另一種放空方式，費率與規則不同，未模擬。
- **2025 年 4–5 月與 2022–2023 的借券賣出委託數量限制**：只影響借券賣出，不影響融券，未模擬。
- **歷史成分股**：2013 年以前的平盤以下豁免需要當年的指數成分股名單，目前以保守方式處理。
