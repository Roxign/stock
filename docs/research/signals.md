# 買賣訊號與通知

網頁「今日訊號」與個股頁的「今日訊號」面板，由 `stocklab/signals.py` 產生（`docs/data/signals.json`），每天收盤後由 `daily_update.py` 更新。

## 訊號從哪裡來

回測的規則是「收盤時決定部位、隔天開盤成交」。所以每個策略在最新一根 K 棒收盤後的決定，就是它**下一個交易日開盤**要下的單：

| 部位變化 | 委託 |
|---|---|
| 空手 → 多 | 買進 |
| 多 → 更多 / 更少 | 加碼 / 減碼 |
| 多 → 空手 | 賣出 |
| 空手 → 空（融券） | 放空 |
| 空 → 空手 | 回補 |
| 多 → 空、空 → 多 | 賣出並放空、回補並買進 |

這些委託和網頁上的回測、K 線上的買賣點是同一套計算，不會「事後重畫」：收盤後的決定不會因為之後的資料而改變（每個策略都通過截斷資料的前視檢查）。

放空會再檢查最新的融資融券資料：若下一個交易日停止融券賣出（除權息、股東會前），會標示「無法放空」。

## 觸發價（目標價）

很多規則（KDJ、MACD 翻揚、均線、停損）只用該股自己的價格決定。對這些策略，程式在最新 K 棒後面接一根「假設的明日 K 棒」——開盤＝今日收盤、收盤＝x、最高／最低＝兩者較大／較小、成交量＝20 日平均——讓 x 在 ±10%（漲跌停）之間以 0.5% 的間距變動，重算策略的決定，再用二分法把轉折點精確到升降單位（tick）。結果寫成：

- 「收盤 ≤ 645 → 賣出」：明日收盤若在 645 以下，策略會發出賣出訊號（**後天開盤**執行）；停損也是這樣算出來的。
- 「收盤 ≥ 19.35 → 加碼」、「收盤 134～143.5 → 買進」：上漲突破或落在某個區間才會觸發。
- 「±10% 內無」：明天不論怎麼漲跌，這個策略都不會改變部位。

限制：
- 假設的 K 棒沒有上下影線，用到最高／最低價的指標（KDJ）實際值會略有不同；以收盤後的實際訊號為準。
- 深度學習、跨股票（例如「個股＋大盤雙趨勢」要看 50 檔等權指數）與多資產（月底調整）的策略，決定取決於模型或其他標的，無法事先算出觸發價，只顯示收盤後的委託。
- 程式會先檢查：把策略只套在單一股票上，結果必須和套在全部股票上完全相同，才會計算觸發價。

網頁的「接近觸發」表列出明日收盤只要再變動 ±1%／3%／5%／10% 以內就會出現的訊號；個股頁的 K 線會把觸發價畫成虛線（紅＝買方、綠＝賣方），明日開盤的委託畫成圓點。

## 訊號品質：過去的買賣點準不準

對每個策略的每一次買點（部位增加 ≥ 25%）與賣點（部位減少 ≥ 25%），計算成交日開盤到 5、20 個交易日後開盤的漲跌，減去同一檔股票在同一期間任意一天的平均漲跌，得到**超額漲跌**：

- 買點後的超額漲跌 > 0：買在比平常更好的時點。
- 賣點後的超額漲跌 < 0：賣掉之後股價走弱，賣得好；> 0 代表賣掉後反而漲得比平常多。
- 「上漲比例 / 平常」：買點後 20 日上漲的比例，和任意一天買進後 20 日上漲的比例比較。

另列完整交易（空手→持有→空手）的勝率、平均每筆報酬（含手續費與稅）與平均持有天數。分樣本內（2010–2020）、樣本外（2021–今），以及 50 檔、另 55 檔代表股、ETF。

## 結果（資料至 2026-10-08）

### 買點

- 有 8 個策略的買點，在所有有資料的樣本（50 檔、另 55 檔代表股或 ETF，各分樣本內與樣本外）買進後 20 日都比平常多漲，網頁標示「買點穩定」：MACD趨勢＋KDJ三線超賣反彈、同步翻揚買／MACD死叉才賣、超跌反彈組合、拉回買進・過熱賣出、Connors RSI(2)、月營收＋籌碼 GBDT（只有 50 檔）、ETF 的 KDJ+MACD 反彈多空、ETF 趨勢多空。幅度多半是 20 日多漲 0.3%～1.5%，不大，但方向一致，而且在開發時沒用過的 55 檔代表股上也成立。
- 你提出的規則（KDJ 與 MACD 零軸下同步翻揚）的買點：50 檔樣本內 +0.4%、樣本外 +0.3%，代表股樣本內持平、樣本外 +0.8%，略優於平常。
- 深度學習策略的買點多半不穩定，例如跨股注意力樣本內 +1.3%、樣本外 −2.6%，趨勢標籤 TCN 樣本外 −1.8%。

### 賣點

- 大部分策略賣出後，股價 20 日內反而比平常**多漲**（超額漲跌為正）：在長期向上的台股，技術指標轉弱的賣點多半只是短暫回檔。
- 賣點在所有樣本都穩定的只有兩個：「成本感知部位網路」（但它的買點很差，等於整體方向相反）和多資產的「趨勢＋風險平價」。
- 所以停損與賣出訊號的主要作用是限制單筆虧損與回撤，不是預測下跌。

### 怎麼使用這些通知

- 優先看「買點穩定」策略的**買進**通知，當成「比平常好的加碼時點」；可在「關注的策略」按「只選訊號穩定的」。
- 賣出通知的參考價值較低；如果採用，是為了控制風險，不要期待它能避開下跌。
- 這也呼應[診斷報告](diagnosis.md)：策略的買點有一點優勢，但賣出後錯過的漲幅更大，所以整體很難贏過買進持有。值得接著研究的方向是「定期定額＋用穩定買點加碼、不依賣訊出場」。

## 通知

目前不綁定通知管道。網頁「今日訊號」最下方的「通知文字」依目前的篩選（標的、買方／賣方、關注的策略、距離）產生一段可直接貼到 LINE、Email 的文字；Python 端 `stocklab.signals.digest()` 產生相同格式，之後要接 LINE（Messaging API）、Telegram Bot、Email 或手機推播時，只要在 `daily_update.py` 最後送出這段文字即可。關注的策略會記在瀏覽器裡（每台裝置各自設定）。
