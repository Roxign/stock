# 強化學習（RL）實驗與瓶頸分析

（2026-10-13，資料至 2026-10-08；程式在 `strategies/rl/`。開發期 2013–2020 逐年前推：每年 1 月只用之前的資料重新訓練，再交易那一年；
2021 年後的樣本外只對事先凍結的設定跑一次。標的是 50 檔成分股加 55 檔代表股共 105 檔，費用與回測引擎相同：隔天開盤成交、
買 0.1425%、賣 0.4425%（含證交稅）、放空另加融券費。所有設定都記錄在 `research/trials.jsonl`（agent = `rl`）。）

## 結論摘要

1. **RL 沒有突破。** PPO、直接強化學習、完整資訊 Q 學習（FQI）、模仿完美交易者、自學序列特徵、看得到每個數值歷史的 TCN／GRU、RL 跨股配置、跨市場加槓桿，
   前後試了 100 多種設定，沒有一種在樣本外穩定勝過買進持有。PPO 只要獎勵是「比買進持有多賺多少」，就收斂成持股 93–100%，
   也就是預期中的「買了不動」。開發期最好的 5 個設定凍結後在 2021 年後各跑一次，擇時 t 值在 −1.8 和 +0.6 之間，全部不顯著。
2. **瓶頸是資訊量，不是演算法。** 要贏過買進持有，預測和未來報酬的相關（IC）需要約 **0.12–0.2**；
   實際做到的是個股技術面 0.03–0.06、籌碼面約 0。只有大盤狀態對 20–60 天有 0.11–0.16，但那是 105 檔共用的同一注，
   放到 7 個市場一起看就消失了。「植入已知訊號」的測試證明學習器沒問題：直接強化學習在植入日 IC 0.05 的慢訊號時就找得到
   （擇時 t = +2.5），0.10 時 93% 的股票勝過買進持有。只有 PPO 是弱學習器，連植入的訊號都找不到。
3. **手續費是第二個瓶頸。** 不用付費時，每天決策只要 IC 0.02 就能贏；股票的手續費加證交稅把門檻拉高到 0.2，等於 10 倍。
   每天的大盤訊號其實存在（IC 約 0.055，開發期與樣本外都是正的），改用期貨級成本後，從大賠變成大約打平，但還是不夠強。
4. **100% 持股上限加上長期上漲。** 不能加碼時，「現在比平常好」的訊號用不上，只能減碼，而減碼在上漲市場裡就是少賺。
   允許最高 150%（期貨或融資）後，開發期贏了，樣本外又輸了。
5. **基準被倖存者偏差墊高。** 2021 年後，今天的 50 檔成分股中位年化 36.4%，其他 55 檔只有 9.2%；
   在事後挑出的贏家上，任何減碼都會吃虧。
6. **跨股動能一度看起來是例外，在沒有倖存者偏差的股票池上就消失了。** 在原本的 105 檔上，「每月持有近一年最強的 20 檔」
   2021 年後仍勝過等權，扣掉 beta 後每年多約 5%（t = 2.3）。但改用 2008 年以來所有上市股票（含 193 檔後來下市的），
   每月只從「當時」成交金額最大的 50／100／200 檔裡挑，扣掉 beta 後的超額變成 0.0%、−0.9%、−1.4%，Sharpe 都比等權低。
   多賺的部分只是買到 beta 約 1.3 的股票；原本的 alpha 主要來自「用 2026 年的眼光挑出 105 檔」這件事（第四節）。
7. **兩個結構性發現：**
   - 台股的報酬幾乎都在**夜間**賺到：收盤到隔天開盤年化 +38%，盤中 −25%。
     美股消息在台股開盤前就已反映（美股費半與隔天開盤跳空相關 0.37，與開盤之後的可交易報酬 −0.06）。
   - **加權指數的「開盤價」不能拿來回測。** 那是 9:00 第一筆指數值，還沒成交的股票沿用前一天價格，會落後於隔夜消息。
     用它回測，同一個模型在 2021 年後顯示日 IC 0.21、Sharpe 2.3；改用 0050 真實的開盤成交價只剩 0.06–0.07。

## 一、瓶頸診斷（`bottleneck.py`，開發期 2013–2020，105 檔中位數）

買進持有：中位年化 10.9%、Sharpe 0.59、最大回撤 −47%；105 檔等權組合 Sharpe 1.15。

### 1. 上限：完美預知能賺多少

| 決策頻率（完全知道下一段的漲跌，只持有較好的一半） | 中位年化 | Sharpe |
|---|---|---|
| 每天都知道明天（最佳路徑，含費用） | 316% | – |
| 每 1 天 | 284% | 6.58 |
| 每 5 天 | 108% | 3.46 |
| 每 20 天 | 51% | 1.97 |
| 每 60 天 | 27% | 1.35 |
| 每 120 天 | 21% | 1.13 |

天花板很高，所以不是「沒有空間」，而是看不準。

### 2. 需要多準：雜訊預言者

模擬一個預言者，它的訊號和未來 H 天報酬的相關是 ρ（ρ = 1 就是完全知道），持有它最看好的 50% 或 80% 時段，扣真實費用：

| 每 H 天決定一次 | 追平買進持有需要的 ρ（有費用） | 零成本時需要的 ρ |
|---|---|---|
| 1 天 | 約 0.20–0.22 | 約 0.02 |
| 5 天 | 約 0.12–0.15 | 約 0.03–0.05 |
| 20 天 | 約 0.12 | 約 0.08–0.10 |
| 60 天 | 約 0.15 | – |

### 6. 統計檢定力

要讓「策略比買進持有好」達到 t = 2，資訊比率（超額報酬 ÷ 追蹤誤差）在 8 年裡需要 0.71，在 5.8 年的樣本外需要 0.83。
一般的擇時策略能做到 0.2–0.3 就算很好，所以就算有真的優勢，這段資料也很難證明。

## 二、怎麼逼模型不要「買了不動」

| 設計 | 想法 | 結果 |
|---|---|---|
| 獎勵改成「比買進持有多賺多少」 | 一直持有的分數變成 0 | 數學上最佳解不變（只是扣掉一個常數）；PPO 仍然收斂到持股 93–100% |
| 強制平均持股 50% / 80% | 必須挑出比較好的日子 | 學得出穩定的半倉，但沒有擇時能力（和固定半倉一樣） |
| 去掉每檔的長期漲勢 | 只剩擇時能賺錢 | 持股降到 14–28%，大輸 |
| 市場中性（減掉當天平均） | 改比哪檔比較強 | 年化約 −1%，沒有選股能力 |
| 加大探索（熵獎勵 ×5） | 多試不同動作 | 和原本一樣收斂到幾乎一直持有 |
| 訓練時把手續費放大 3 倍 | 防止來回洗 | 年換手降到 0.4，最大回撤從 −47% 降到 −26%，Sharpe 與買進持有相同，但沒有擇時 |
| 跨股配置（永遠滿倉，比的是持有哪幾檔） | 「一直持有」不是現成答案 | 見第四節 |
| 槓桿上限 150% | 讓「比平常好」的訊號用得上 | 開發期贏，樣本外輸（第五節） |
| 換成期貨級成本 | 讓快訊號付得起 | 從大賠變打平（第五節） |

因為認得出來的，是一段漲勢「已經漲了」的部分，例如過去 20 天漲很多、KD 在高檔；真正能賺錢的是還沒發生的那段，那部分認不出來。

### 讓模型看到每個數值過去一段時間的變化（`history.py`）

上面的模型每次只看「今天」的 65 個數值（雖然很多數值本身是用過去資料算的）。這裡讓模型直接看到每個數值的歷史：

- **滯後特徵＋線性：** 65 個數值各取今天、1、2、5、10、20、40、60 天前，共 520 個輸入；
- **TCN（因果卷積網路）：** 直接讀 65 個數值過去 64 天或 128 天的序列；
- **GRU（循環網路）：** 一天一天讀進 65 個數值，記憶先用預測日之前的 250 天暖機，約可學到 250 天以內的規律。

預測力（擇時 IC／橫斷面 IC，開發期逐年前推）：

| | 預測 1 天 | 5 天 | 20 天 | 60 天 |
|---|---|---|---|---|
| 線性・只看今天 | 0.058 / 0.038 | 0.069 / 0.053 | 0.110 / 0.040 | 0.156 / 0.061 |
| 線性・看過去 60 天 | 0.030 / 0.033 | 0.053 / 0.050 | 0.100 / 0.041 | 0.121 / 0.041 |
| TCN・64 天 | | | 0.135 / 0.017（換種子：0.028、0.023） | |
| TCN・128 天 | | | 0.056 / 0.016 | |
| GRU・約 250 天 | | 0.049 / 0.047 | 0.076 / 0.030 | 0.093 / 0.041 |

直接以回測績效訓練（買進持有 10.9% / 0.59；只看今天的同一目標是 6.3% / 0.48，持股 62%，擇時 t −0.2）：

| 模型 | 目標 | 年化 | Sharpe | 最大回撤 | 平均持股 | 年換手 | 擇時 t |
|---|---|---|---|---|---|---|---|
| TCN・64 天 | 最大化對數報酬 | 10.1% | 0.53 | −45% | 87% | 2.4 | −0.0 |
| | 強制持股 50% | 5.7% | 0.57 | −26% | 50% | 0.9 | −0.4 |
| TCN・128 天 | 最大化對數報酬 | 7.6% | 0.49 | −45% | 84% | 1.2 | −0.9 |
| GRU・約 250 天 | 最大化對數報酬 | 6.3% | 0.46 | −41% | 64% | 7.3 | −0.1 |
| | 強制持股 50% | 5.7% | 0.51 | −27% | 51% | 5.0 | −0.2 |

- 線性模型多看 60 天，四種預測期間的 IC 全部**下降**：輸入變 8 倍，學到的過去雜訊也變多。
- 網路模型能自己挑重點，但也沒有變好。唯一較高的 TCN 64 天（0.135）換兩個隨機種子只剩 0.028 和 0.023，是運氣。
- 直接交易時，看得到歷史的模型會比較接近一直持有（持股 84–87%），但擇時 t 值都在 0 附近或負的。
- 結論：瓶頸不是「模型看不到過去」。這些數值的歷史裡沒有比「今天的值」更多、能穩定預測未來的資訊。

### 學習器能力測試：植入已知訊號（`planted.py`）

把一個已知強度的訊號加進真實報酬（R' = R + β·z·σ，z 是學習器看得到的某個特徵），其餘條件不變，看學習器能不能找到並賺到錢。
慢訊號用「距季線」（每天變化很小），快訊號用「昨天漲跌」（每天都不一樣）；表內是擇時 t 值，括號是 105 檔等權組合的 Sharpe（買進持有約 1.0–1.15）：

| 植入的日 IC | 0 | 0.01 | 0.02 | 0.03 | 0.05 | 0.10 |
|---|---|---|---|---|---|---|
| 慢訊號・直接強化學習 | −0.2（0.93） | +0.0（0.97） | −0.0（0.97） | +1.1（1.11） | **+2.5（1.27）** | **+9.3（2.15）** |
| 慢訊號・監督式預測 20 天 | −2.1 | −1.9 | −1.7 | −1.3 | −0.2 | +3.8（1.47） |
| 慢訊號・PPO | | | −1.6（持股 98%） | | +0.5（持股 99%） | |
| 快訊號・直接強化學習 | −0.2 | −0.2 | −0.4 | −0.4 | −0.5 | −0.1 |
| 快訊號・監督式預測 1 天 | −5.3 | −5.6 | −5.8 | −6.1 | −6.3 | −6.3 |
| 快訊號・PPO | | | −0.7（持股 94%） | | −1.0（持股 94%） | |

- **直接強化學習是有能力的學習器**：慢訊號只要日 IC 0.05（大約是 60 天 IC 0.3 以上），它就找得到並賺到錢；0.10 時 93% 的股票勝過買進持有。
  所以它在真實資料上失敗，是因為資料裡沒有這麼強、這麼穩定的訊號。
- **PPO 是比較弱的學習器**：連明確存在的日 IC 0.05 慢訊號都找不到，仍然被「一直持有」吸過去。
  PPO 只看得到自己做過的動作的結果，在這種雜訊很大的環境裡效率太低；直接強化學習則利用了「每個動作的結果都算得出來」。
- **快訊號在台股的費用下根本付不起**：日 IC 0.10、每天都在變的訊號，所有學習器都賺不到；直接強化學習正確地選擇不去交易它。
  這和第一節的估算一致：每天決定一次需要 IC 約 0.2。

## 四、跨股配置：比的是「持有哪幾檔」（`alloc.py`、`momentum.py`）

擇時對每檔股票每次只有一注，還要和長期漲勢對抗；跨股配置永遠滿倉，比的是持有哪幾檔，105 檔每次調整等於 105 注小賭注。
這是瓶頸分析裡唯一「門檻比較低」的方向（橫斷面 IC 0.04–0.08，靠檔數放大）。

開發期 2013–2020、每 5 天調整一次（`alloc.py` 的快速向量化回測）：

| 組合 | 年化 | Sharpe | 最大回撤 |
|---|---|---|---|
| 等權（每期再平衡） | 16.8% | 1.06 | −29% |
| 0050 買進持有 | 15.1% | 1.03 | −26% |
| 動能：近一年最強 20 檔 | **23.8%** | 1.10 | −31% |
| 動能：近 60 日最強 20 檔 | 21.6% | 1.11 | −32% |
| 反轉：近 5 日最弱 20 檔 | 1.8% | 0.19 | −48% |
| 低波動 20 檔 | 7.7% | 0.74 | −22% |
| 動能（只用 55 檔代表股） | 21.3% | **1.18** | −32% |
| 等權（只用 55 檔代表股） | 15.0% | 0.97 | −30% |
| RL 配置器：全部特徵 | 5.6% | 0.33 | −62% |
| RL 配置器：Sharpe 目標 | 25.3% | 1.06 | −37% |
| RL 配置器：只用 55 檔代表股 | 36.1% | 1.02 | −43% |

每 20 天調整一次時，RL 配置器在開發期看起來很驚人（全部特徵 50.1% / 1.13；Sharpe 目標 30.5% / **1.89**，等權 17.4% / 1.27；
20 天一期的數字以每期報酬計算，和上表不能直接比）。但同一個方法每 5 天調整一次只有 5.6%，差這麼多，代表結果非常不穩定。
它只集中押約 6 檔；在含有倖存者偏差的股票池裡，集中押注很容易押中後來大漲的股票。凍結後在樣本外只跑一次：

| 樣本外 2021–（每 20 天調整） | 年化 | Sharpe | 最大回撤 |

| RL 配置器：Sharpe 目標 | 28.7% | 1.57 | −18% |

| 動能：近一年最強 20 檔 | 58.1% | 1.68 | −28% |
| 動能（只用 55 檔代表股） | 26.6% | 1.25 | −21% |
| 等權（只用 55 檔代表股） | 16.3% | 1.07 | −18% |

RL 配置器在樣本外輸給等權，只用 55 檔的版本更是幾乎爆掉；最簡單的動能規則反而在兩種股票池都比等權好。
用專案原本的投資組合引擎（`stocklab.portfolio`：同一帳戶、隔天開盤成交、各自的費用、每月第一個交易日換股）複核「近一年最強 20 檔」：

| | 樣本內 2010–2020 | 樣本外 2021– | 8 段交叉驗證：年化勝等權 | Sharpe 勝等權 |
|---|---|---|---|---|
| 105 檔：動能 | 23.1% / 1.05 / −41% | 49.5% / 1.41 / −38% | 5 段 | 3 段 |
| 105 檔：等權 | 13.8% / 0.90 / −30% | 37.0% / 1.60 / −28% | | |
| 55 檔代表股：動能 | 21.0% / 1.07 / −35% | **23.4% / 1.02** / −35% | 6 段 | 5 段 |
| 55 檔代表股：等權 | 14.2% / 0.91 / −32% | 16.7% / 0.93 / −28% | | |
| 0050 買進持有 | 10.7% / 0.73 / −28% | 29.6% / 1.29 / −34% | | |

2010 年至今，55 檔代表股的動能組合每年比等權多 7.2%（t = 3.2），但它的 beta 是 1.13，也就是買到的多半是漲跌幅較大的股票。
扣掉 beta 之後，超額剩年化 +5.0%（t = 2.3）；105 檔則剩 +3.6%（t = 1.2）。
在這 105 檔上，它是整個研究裡唯一在樣本外仍然成立的優勢。但這 105 檔是 2026 年挑出來的（今天的成分股、被剔除的前成分股和
今天的產業龍頭），所以接著用「當年真的存在的全部上市股票，包含後來下市的」重新驗證，結果它不成立：

### 用「當時真的存在的全部上市股票」重新驗證（`fulluniverse.py`、`momentum_full.py`）

股票清單：FinMind 的上市公司資料加上下市櫃清單，共 1,272 檔普通股，其中 191 檔已下市（矽品、日月光、晶電、中壽、華亞科、新光金……）。
還在上市的用 Yahoo 還原股價，已下市的用 FinMind 原始股價加除權息自行還原。每月第一個交易日，只用「當時」的資料決定股票池：
有一年以上歷史、過去 60 天平均成交金額最大的 N 檔，再持有其中近一年漲最多的 20%。下市股票停留在最後成交價。

| 2010 年至今 | 年化 / Sharpe（等權） | 年化 / Sharpe（動能） | 每年多賺（t） | beta | 扣 beta 後（t） | 8 段中年化勝 / Sharpe 勝 |
|---|---|---|---|---|---|---|
| 含下市股・前 50 大 | 15% / 0.73 | 17% / 0.62 | +5.1%（1.0） | 1.29 | **0.0%（0.0）** | 6 / 4 |
| 含下市股・前 100 大 | 13% / 0.68 | 14% / 0.58 | +3.8%（1.0） | 1.31 | **−0.9%（−0.2）** | 4 / 3 |
| 含下市股・前 200 大 | 11% / 0.64 | 11% / 0.54 | +2.1%（0.7） | 1.27 | **−1.4%（−0.5）** | 5 / 2 |
| 只用今天仍上市的・前 100 大 | 14% / 0.71 | 17% / 0.67 | +5.1%（1.3） | 1.26 | +0.8%（0.2） | 5 / 3 |
| 0050 買進持有 | 17% / 0.95 | | | | | |

- 在時間點正確的股票池上，動能沒有 alpha：多賺的報酬完全可以用「beta 比較高」解釋，Sharpe 反而比等權低。
- 「含下市股」與「只用今天仍上市的股票」差別不大（扣 beta 後 −0.9% 對 +0.8%）。原本 105 檔上的 alpha，主要來自
  **用 2026 年的眼光挑出這 105 檔**（今天的成分股與產業龍頭，本身就是事後的贏家），而不只是少了下市股。
- 這也提醒：任何只在「今天挑出來的股票」上做的回測，都會高估選股策略。

## 五、大盤擇時：跨市場、槓桿、期貨成本

### 7 個市場一起學 + 最高 150% 曝險（`market.py`）

只用台股訓練、預測 60 天、最高 150%、融資成本 3%，交易 0050：

| | 策略 | 0050 買進持有 | 同平均曝險固定持有 |
|---|---|---|---|
| 開發期 2013–2020 | 17.6% / Sharpe 1.10 / MDD −31% | 14.5% / 0.99 / −26% | 12.3% / 0.99 |
| 樣本外 2021– | 22.6% / 1.09 / −46% | 30.5% / 1.34 / −34% | 25.9% / 1.34 |

7 個市場（台、美 S&P 與那斯達克、日、韓、港、滬）一起學時，各市場的擇時差距平均是 −0.2% 到 −1.6%（開發期）、
−0.7% 到 −1.3%（樣本外），7 個市場裡只有 1–3 個勝過同曝險的固定持有。結論：台股開發期的好成績是那段期間的巧合。

### 每天的大盤訊號 + 期貨級成本（`futures.py`）

以 0050 真實開盤價當作台指期的代理，每天依大盤模型決定隔天的曝險：

| 預測 1 天 | 日 IC | 期貨級成本（0.01%/邊）：做多或空手 | 同平均曝險固定 | 擇時 t | ETF 級成本：做多或空手 |
|---|---|---|---|---|---|
| 開發期 | +0.055 | 12.4% / 0.99 | 9.6% / 0.99 | +1.2 | 0.4% / 0.09 |
| 樣本外 | +0.058 | 19.4% / 1.09 | 17.6% / 1.34 | +0.5 | 0.7% / 0.13 |

訊號在兩段都存在，期貨級成本也讓它從大賠變成小贏過同曝險，但 t 值不到 2，Sharpe 沒有比較好，最大回撤還更大。

### 定期定額挑日子買（`execution.py`）

反正每個月都要買，就用每天的訊號決定「這個月哪天買」，手續費一毛都不會多付：

| 規則（開發期，105 檔中位） | 多買到的股數 |
|---|---|
| 預測 1 天，等到前 50% 的日子才買 | +0.10% |
| 預測 20 天，等到前 50% 的日子才買 | −0.11% |
| 月底才買 | −0.77% |
| 每月最便宜那天（事後才知道） | +4.32% |

弱訊號連挑哪天買都幫不上忙。

## 六、樣本外一次性驗證（`final_oos.py`）

從開發期挑出的 5 個設定先凍結，再對 2021 年後只跑一次（仍是每年 1 月用之前的資料重訓）。
105 檔買進持有在這段期間是中位 20.3% / Sharpe 0.84 / −48%；55 檔代表股是 9.2% / 0.47 / −50%。

| 設定（挑選理由） | 105 檔：年化 / Sharpe | 擇時 t | 55 檔代表股：年化 / Sharpe | 擇時 t |
|---|---|---|---|---|
| FQI 梯度提升（開發期擇時最好，t = +1.6） | 3.3% / 0.31 | −1.5 | −2.7% / 0.01 | −1.8 |
| FQI 線性、持有前 80%（開發期等權 Sharpe 最好） | 19.6% / 0.81 | −0.1 | 7.6% / 0.45 | +0.2 |
| 模仿完美交易者（開發期等權組合 Sharpe 1.25） | 14.1% / 0.63 | −1.3 | 3.9% / 0.28 | −1.3 |
| PPO 相對買進持有 | 18.8% / 0.78 | −1.1 | 9.1% / 0.43 | −0.8 |
| 直接強化學習＋平滑 | 16.0% / 0.68 | +0.6 | 6.3% / 0.39 | +0.2 |

開發期最好的擇時設定，到了樣本外不是變成負的，就是剛好等於買進持有。跨股動能則在樣本外仍然成立（見第四節）。

## 七、這代表什麼、接下來可以做什麼

- 用現有的免費日資料（價量、籌碼、國際市場），擇時的資訊量大約只有勝過買進持有所需的三分之一。
  換任何演算法（RL、深度學習、模仿學習）都補不起這個缺口，RL 只會更誠實地收斂到「一直持有」。
- **選股方向也驗證過了：** 跨股動能在 105 檔上看起來有效，但在時間點正確、含下市股的全部上市股票上沒有 alpha。
  以後評估任何選股策略，都要用 `strategies/rl/momentum_full.py` 這種「當時的股票池」，不能用今天挑出來的股票。
- **0050 本身就很難打敗：** 在時間點正確的股票池上，2010 年至今 0050 買進持有是年化 17% / Sharpe 0.95，
  成交金額前 100 大等權只有 13% / 0.68，動能 14% / 0.58。這段期間台積電主導了市場，市值加權的 0050 自然佔優。
- 另一個還有一點證據的方向是「每天的大盤訊號 + 期貨級低成本」，但目前不顯著。要繼續的話，需要真實的台指期日盤開盤價
  （FinMind `TaiwanFuturesDaily`），加上滑價與轉倉成本再驗證一次。
- 想讓報酬變高，比擇時更實際的是：降低成本（券商手續費折扣）、用沒有倖存者偏差的基準評估、用資產配置降低回撤
  （之前的「股債金切換」在樣本外 Sharpe 1.34，回撤 −21%，0050 是 −34%）。
- 要提高 IC，就需要新的資訊來源：財報與法說的驚喜、新聞情緒、盤中資料、選擇權隱含波動。這些不在目前的免費日資料裡。
