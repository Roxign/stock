{ =====================================================================
  dl_market_state_mlp ── 市場狀態 MLP 共同曝險（50% / 75% / 100%，只做多）
  ---------------------------------------------------------------------
  這個策略用「一個大盤層級的小型 MLP」（39 個市場特徵 → 16 個 tanh → 1 個 sigmoid，
  每年重新訓練 5 個不同種子的網路取平均，合計 3,285 個參數）決定所有 50 檔共用的
  曝險 g_t。輸入包含三大法人、融資、借券、台指選擇權 put/call、外資台指期/選擇權
  未平倉、美股/日韓股市、VIX、美債、美元、台幣等外部資料，MultiCharts 裡沒有這些資料，
  也無法重算模型，所以由 Python 每天算好「每檔股票的目標曝險」，匯出成 ASCII 價格檔，
  在 MultiCharts 當作第二個商品 (data2) 讀進來交易。

  data2 的收盤價 = 這一根 K 棒收盤後決定的目標曝險（0.5、0.75 或 1.0），
  下一根 K 棒開盤成交，與 Python 回測（stocklab/backtest.py）的時點完全相同。
  因為是大盤層級的共同曝險，50 個檔案在同一天的數值都一樣（另有 MS_MARKET.txt
  可供只想看大盤訊號時使用）。

  ── 使用步驟 ──────────────────────────────────────────────────────
  1. 每個交易日收盤、資料更新後（data/raw 與外部資料都已含當天，美股為前一晚收盤），
     在 repo 根目錄執行：
        C:\Users\user\.venvs\stock\Scripts\python.exe -m strategies.dl_market_state.export_signals
     約 1～2 分鐘（重跑 2012 起逐年重新訓練的 walk-forward；只用 CPU）。
     輸出：C:\Users\user\OneDrive\Desktop\stock\exports\dl_market_state_mlp\MS_<代號>.txt
     格式：Date,Time,Open,High,Low,Close,Volume，例如 2026/10/02,13:30,1.0000,...,1
     （O = H = L = C = 目標曝險；Volume 固定 1）。
  2. QuoteManager：Import Data → ASCII，每個檔案匯入成一個新商品，
     商品名稱建議 MS_<代號>（例如 MS_2330），日線 (Daily)，
     欄位順序 Date, Time, Open, High, Low, Close, Volume，日期格式 YYYY/MM/DD，
     交易時段與台股相同。第一次建立後，之後每天重新匯入（覆蓋）即可。
  3. 圖表：data1 = 個股日線（還原權值），Insert Symbol 加入 MS_<代號> 當 data2
     （同為日線；可放在隱藏的子圖）。兩者交易日必須一致。
  4. 套用本訊號。只有 data2 的日期等於 data1 當根日期時才更新目標曝險；
     若某天訊號檔缺資料，沿用前一天的目標（並請檢查是否忘了重新匯入）。
  5. 2010～2011 年沒有模型（第一個模型 2012 年起），訊號檔給 1.0（全額持有），
     與 Python 回測一致。

  ── Strategy Properties ──────────────────────────────────────────
    1. 日線、還原權值（除權息調整）價格。
    2. Commission：買賣各 0.1425%；證交稅：賣出 0.3%。若無法只對賣出收稅，
       可用「雙邊各 0.2925%」近似（來回 0.585%，與 Python 回測相同）。
    3. Slippage：依實際情況設定（Python 回測未計滑價，以隔日開盤價成交）。
    4. Position Limits：勾選「Allow up to 4 entry orders in the same direction
       as the currently held position ─ when the order is generated by a
       different entry order」。"Q1"～"Q4" 是四個各 25% 的不同進場單
       （本模型的下限是 50%，所以 Q1、Q2 實際上一直持有）。
    5. Initial Capital 例如 1,000,000；MaxBarsBack 設 5 即可（不需要歷史計算）。

  ── 近似與差異 ───────────────────────────────────────────────────
    ‧ Python 回測每天把部位調整到「目標曝險 × 當時權益」；這裡在進場當下
      以權益的 1/4 為一單位買進，持有期間不再每天再平衡，數量會因股價漲跌
      而偏離 50% / 75% / 100%，報酬會與 Python 回測略有差異。
    ‧ 零股 (LotSize = 1) 最接近回測；整張 (LotSize = 1000) 對高價股的誤差較大。
    ‧ 模型每年 1 月 1 日用當時已知的資料重新訓練（標籤是未來 20 根 K 棒的
      等權大盤報酬，只用前一年底以前已完全實現的樣本）。訊號檔每天重算整段
      歷史，過去的訊號不會因為新資料而改變（已通過截斷前視檢查）。
  ===================================================================== }

inputs:
    LotSize(1);          { 下單單位股數：1 = 零股，1000 = 整張 }

vars:
    Target(1), Eq(0), QQty(0);

{ ---- 讀取 data2 的目標曝險（0.5 / 0.75 / 1.0）---- }
if Date of data2 = Date and Close of data2 > 0 then
    Target = Close of data2;

{ ---- 下單：四個 25% 單位 Q1～Q4，下一根開盤市價成交 ---- }
Eq = InitialCapital + NetProfit + OpenPositionProfit;
QQty = IntPortion(0.25 * Eq / Close / LotSize) * LotSize;

if Target >= 0.125 then begin
    if QQty > 0 then Buy ("Q1") QQty shares next bar at market;
end
else
    Sell ("Q1X") from entry ("Q1") next bar at market;

if Target >= 0.375 then begin
    if QQty > 0 then Buy ("Q2") QQty shares next bar at market;
end
else
    Sell ("Q2X") from entry ("Q2") next bar at market;

if Target >= 0.625 then begin
    if QQty > 0 then Buy ("Q3") QQty shares next bar at market;
end
else
    Sell ("Q3X") from entry ("Q3") next bar at market;

if Target >= 0.875 then begin
    if QQty > 0 then Buy ("Q4") QQty shares next bar at market;
end
else
    Sell ("Q4X") from entry ("Q4") next bar at market;
