{ =====================================================================
  dl_trend_labels_tcn ── 趨勢標籤 TCN 買賣訊號（50% / 100%，只做多）
  ---------------------------------------------------------------------
  這個策略的模型（3 個小型因果 TCN，每個 4,340 個參數，輸入 64 天 × 22 個通道，
  其中 3 個是 50 檔成分股合成的「等權重大盤」通道，另加 39 個表格特徵）無法在 PowerLanguage
  裡重算，所以由 Python 每天算好「每檔股票的目標曝險」，匯出成 ASCII 價格檔，
  在 MultiCharts 當作第二個商品 (data2) 讀進來交易。

  data2 的收盤價 = 這一根 K 棒收盤後決定的目標曝險（0.5 或 1.0），
  下一根 K 棒開盤成交，與 Python 回測（stocklab/backtest.py）的時點完全相同。

  ── 使用步驟 ──────────────────────────────────────────────────────
  1. 每個交易日收盤、資料更新後（data/raw 已含當天日線），在 repo 根目錄執行：
        C:\Users\user\.venvs\stock\Scripts\python.exe -m strategies.dl_trend_labels.export_signals
     約 4～6 分鐘（重跑整段逐年重新訓練的 walk-forward；只用 CPU）。
     輸出：C:\Users\user\OneDrive\Desktop\stock\exports\dl_trend_labels_tcn\TL_<代號>.txt
     格式：Date,Time,Open,High,Low,Close,Volume，例如 2026/10/02,13:30,1.0000,...,1
     （O = H = L = C = 目標曝險；Volume 固定 1）。
  2. QuoteManager：Import Data → ASCII，每個檔案匯入成一個新商品，
     商品名稱建議 TL_<代號>（例如 TL_2330），日線 (Daily)，
     欄位順序 Date, Time, Open, High, Low, Close, Volume，日期格式 YYYY/MM/DD，
     交易時段與台股相同。第一次建立後，之後每天重新匯入（覆蓋）即可。
  3. 圖表：data1 = 個股日線（還原權值），Insert Symbol 加入 TL_<代號> 當 data2
     （同為日線；可放在隱藏的子圖）。兩者交易日必須一致。
  4. 套用本訊號。只有 data2 的日期等於 data1 當根日期時才更新目標曝險；
     若某天訊號檔缺資料，沿用前一天的目標（並請檢查是否忘了重新匯入）。
  5. 2010～2011 年與新上市股票的前 130 根 K 棒沒有模型，訊號檔給 1.0（全額持有），
     與 Python 回測一致。

  ── Strategy Properties ──────────────────────────────────────────
    1. 日線、還原權值（除權息調整）價格。
    2. Commission：買賣各 0.1425%；證交稅：賣出 0.3%。若無法只對賣出收稅，
       可用「雙邊各 0.2925%」近似（來回 0.585%，與 Python 回測相同）。
    3. Slippage：依實際情況設定（Python 回測未計滑價，以隔日開盤價成交）。
    4. Position Limits：勾選「Allow up to 2 entry orders in the same direction
       as the currently held position ─ when the order is generated by a
       different entry order」。"Core"（底倉 50%）與 "Top"（加碼 50%）是兩個
       不同的進場單。
    5. Initial Capital 例如 1,000,000；MaxBarsBack 設 5 即可（不需要歷史計算）。

  ── 近似與差異 ───────────────────────────────────────────────────
    ‧ Python 回測每天把部位調整到「目標曝險 × 當時權益」；這裡在進場當下
      以權益的一半為一單位買進，持有期間不再每天再平衡，數量會因股價漲跌
      而偏離 50% / 100%，報酬會與 Python 回測略有差異。
    ‧ 零股 (LotSize = 1) 最接近回測；整張 (LotSize = 1000) 對高價股的誤差較大。
    ‧ 模型每年 1 月 1 日用當時已知的資料重新訓練（標籤需要往後 120 根 K 棒，
      所以實際只用到約半年前為止的樣本），訊號檔每天重算整段歷史，
      過去的訊號不會因為新資料而改變（已通過截斷前視檢查）。
  ===================================================================== }

inputs:
    LotSize(1);          { 下單單位股數：1 = 零股，1000 = 整張 }

vars:
    Target(1), Eq(0), HalfQty(0);

{ ---- 讀取 data2 的目標曝險（0.5 或 1.0）---- }
if Date of data2 = Date and Close of data2 > 0 then
    Target = Close of data2;

{ ---- 下單：底倉 "Core" 50% + 加碼 "Top" 50%，下一根開盤市價成交 ---- }
Eq = InitialCapital + NetProfit + OpenPositionProfit;
HalfQty = IntPortion(0.5 * Eq / Close / LotSize) * LotSize;

if Target >= 0.25 then begin
    if HalfQty > 0 then
        Buy ("Core") HalfQty shares next bar at market;
end
else
    Sell ("CoreX") from entry ("Core") next bar at market;

if Target >= 0.75 then begin
    if HalfQty > 0 then
        Buy ("Top") HalfQty shares next bar at market;
end
else
    Sell ("TopX") from entry ("Top") next bar at market;
