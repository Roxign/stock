# KDJ + MACD 反彈策略研究筆記

使用者指定的規則：

> 以 KDJ 與 MACD 為主，但是邏輯採用 KDJ 與 MACD 皆開始反彈時，且 MACD 須為負，此時為買入訊號；然後 KD 與 MACD 往下，且 MACD 為正時，賣出；買進有停損設定。

本筆記把這段話的每個詞轉成程式能判斷的條件，只用樣本內（2010–2020）比較各種讀法，凍結設計後再做 8 折交叉驗證、對照組，最後只跑一次樣本外（2021-01-01 ～ 2026-10-02）。
標的為元大台灣50（0050）目前 50 檔成分股（樣本內 49 檔有資料），比較基準為買進持有與定期定額。

## 0. 結論摘要

- **忠實版 `kdj_macd_rebound_turn`**（K 值與 MACD 柱狀體同一天勾頭向上、DIF 與 MACD 線都 < 0 買；K 值與柱狀體同一天勾頭向下、兩線都 > 0 賣；10% 收盤停損）：
  - 樣本內 CAGR 1.5% / MDD −39.6% / Sharpe 0.18（買進持有 8.8% / −46.1% / 0.48），持股率 37%。
  - 樣本外（只跑一次）CAGR 5.3% / MDD −34.1% / Sharpe 0.47（買進持有 35.7% / −45.5% / 1.10），沒有任何一檔報酬勝過買進持有。
  - 8 折交叉驗證 **0/8 折** Sharpe 勝過買進持有；三個對照組（固定持股、別檔訊號、波動目標）在樣本內都比它好。
- **變體 `kdj_macd_rebound_deadcross`**（買進相同；賣出的「MACD 往下」改讀成 MACD 死亡交叉）：
  - 樣本內 6.4% / −46.4% / 0.42，持股率 76%；樣本外 18.4% / −42.5% / 0.80；交叉驗證同樣 **0/8 折**勝過。
  - 比忠實版好的部分幾乎全部來自「持有比較多」：同持股率的固定持股、別檔訊號在樣本內與樣本外都比它好。
- **為什麼不行**：事件研究顯示買進訊號後 5～40 天沒有超額報酬（t 值都在 ±0.5 以內）。「零軸下的反彈」本來就是空頭反彈，賣出條件（柱狀體一勾頭向下）又在多頭的第一次小回檔就下車；
  每檔每年約 3 次來回、每次成本 0.585%，沒有資訊的訊號只會變成成本。
- **在空頭／盤整有沒有幫助？** 只在明顯空頭年有一點：忠實版在 2011 年（+9.1 個百分點）、2022 年（+4.5）勝過買進持有，2020 疫情急跌期間少虧一半（−13.0% vs −26.0%）。
  但 2014–15（2015 股災）、2018–19 這些弱勢折反而更差，而且依當時持股率換算，急跌段的表現大多不如「同持股率的固定持股」。整體而言它是「持股較少的買進持有再扣掉成本」，不是空頭避險工具。
- 發布兩個版本：忠實版（主策略）與 MACD 死叉賣出版（說明「同一句口訣、不同讀法」的差距）。**兩者都不建議實際使用。**

整理：台灣教學中的「翻揚／開始反彈」可以是 K 值勾頭、KD 黃金交叉、柱狀體（綠柱）縮短或 DIF 勾頭；「MACD 為負」通常指 DIF、MACD 兩條線在零軸下。
值得注意的是，上面三篇 MACD 教學都把**零軸下的反彈**視為弱勢反彈 —— 使用者的規則剛好是買在這裡。

## 2. 每個詞的操作化（樣本內測過的讀法）

| 使用者的詞 | 測過的讀法 | 發布的讀法 |
|---|---|---|
| KDJ 開始反彈 | K 勾頭向上（K[t] > K[t−1] 且 K[t−1] ≤ K[t−2]）／J 勾頭向上／KD 黃金交叉 | **K 勾頭向上** |
| MACD 開始反彈 | 柱狀體 OSC 勾頭向上（綠柱開始縮短）／DIF 勾頭向上／MACD 黃金交叉（DIF 穿越 MACD 線） | **柱狀體勾頭向上** |
| 皆（兩者都） | 同一天；或 3 天、5 天內先後出現（後出現的那天觸發，且兩者當天仍在上升；另測不要求「仍在上升」） | **同一天** |
| MACD 須為負 | DIF < 0／MACD 線 < 0／兩線都 < 0／OSC < 0 | **DIF < 0 且 MACD 線 < 0** |
| KD 與 MACD 往下 | K 勾頭向下／J 勾頭向下／KD 死叉 × 柱狀體勾頭向下／DIF 勾頭向下／MACD 死叉，同一天或 3 天內 | 主策略：**K 勾頭向下＋柱狀體勾頭向下（同一天）**；變體：K 勾頭向下＋**MACD 死叉** |
| MACD 為正 | 與「為負」對稱；另測完全不限制 | **DIF > 0 且 MACD 線 > 0** |
| 停損 | 不停損／收盤 < 進場價 × (1 − s)，s = 5%、7%、10%、12%、15%、20%／收盤 < 進場價 − k × ATR14（訊號當天），k = 2、3、4 | **收盤 < 進場價 × 0.9** |

實作細節：
- 指標：`tw_kdj`（9,3,3、1/3 平滑、初值 50、J = 3K − 2D）、`macd`（12,26,9；`dif`、`macd` 為訊號線、`osc` = DIF − MACD）。
- 回測引擎在第 t 根收盤決定部位、第 t+1 根開盤成交。進場價 = 買進訊號隔天的**開盤價**，所以停損從進場那根 K 棒的**收盤**才開始檢查；收盤跌破停損價 → 隔天開盤賣出。
  MultiCharts 對應：`if Close < EntryPrice * (1 - s) then Sell next bar at market`（不能用 SetStopLoss，它在盤中觸價就出場）。
- 停損或賣出後，必須出現新的買進訊號才會再進場；持有期間出現的買進訊號不加碼（0/1 部位）。
- 一組參數套用全部 50 檔。

## 3. 研究設定

- 開發只用樣本內 2010–2020。表格中的「f1～f5」是樣本內的五個 2 年子期間（2010–11、2012–13、2014–15、2016–17、2018–19）的 Sharpe 中位數，買進持有分別為 0.05 / 0.70 / 0.29 / 0.80 / 0.65。
- 研究用的向量化 0/1 回測與 `stocklab.backtest.simulate` 逐檔比對（CAGR、MDD、Sharpe、持股率、交易數、勝率、平均持有、平均報酬），最大誤差 6e-15；`strategy.py` 與研究程式在 72 組參數格子上逐根部位完全相同（0 根不同）。
- 事件研究的 t 值以月份群聚（clustered by month）計算。
- 所有回測過的設定都記錄在 `research/trials.jsonl`（agent = `kdj_macd_rebound`）：樣本內 149 筆、交叉驗證 72 筆，共 221 筆。

解讀：
- **買進訊號沒有預測力**：所有讀法在 5～40 天的超額報酬都在 ±0.35% 以內、t 值絕對值 ≤ 0.6；與一次來回 0.585% 的成本相比微不足道。「零軸下」比「零軸上」好一點（+23 vs −52 bp @ 40 天），但兩者都不顯著。
- 「兩者同時」並沒有比單一條件（只有 K 勾頭或只有柱狀體勾頭）更好 —— 所謂共振沒有增加資訊，和 `kdj_macd_rule` 引用的 A 股大數據檢驗一致。
- 主策略的賣出訊號之後 5 天股價反而再多漲 +0.08%，20～40 天才略為落後（不顯著）：賣出時機也沒有資訊。

## 6. 發布的策略

| id | 規則 | 樣本內（CAGR / MDD / Sharpe / 持股） |
|---|---|---|
| `kdj_macd_rebound_turn`（主策略、忠實版） | 買：K 勾頭向上＋柱狀體勾頭向上（同一天），DIF < 0 且 MACD < 0；賣：K 勾頭向下＋柱狀體勾頭向下（同一天），DIF > 0 且 MACD > 0；收盤 < 進場價 × 0.9 停損 | 1.5% / −39.6% / 0.18 / 37% |
| `kdj_macd_rebound_deadcross`（變體） | 買進相同；賣：K 勾頭向下＋MACD 死亡交叉（同一天），DIF > 0 且 MACD > 0；同樣 10% 收盤停損 | 6.4% / −46.4% / 0.42 / 76% |

參數格子（`param_grid`，交叉驗證用，各 36 組，都包含發布值）：
- turn：KDJ 讀法（K 勾頭 / J 勾頭 / KD 金叉）× MACD 讀法（柱狀體勾頭 / DIF 勾頭）× 零軸（兩線 / 只看 DIF）× 停損（7% / 10% / 15%）。樣本內 Sharpe −0.04～0.27（中位數 0.10），發布值 0.18 排第 6 / 36。
- deadcross：賣出 KDJ 讀法（K 勾頭 / J 勾頭 / KD 死叉）× 同一天 / 3 天內 × 零軸（兩線 / 只看 DIF）× 停損（7% / 10% / 15%）。樣本內 Sharpe 0.22～0.44（中位數 0.35），發布值 0.42 排第 3 / 36。
- 格子內「持股率」與「樣本內 Sharpe」的相關係數：turn 0.64、deadcross 0.95 —— 參數越接近一直持有，分數越高。

訊號頻率（樣本內，每檔每年）：買進訊號約 8.9 次（持有中出現的不算新交易）；主策略賣出訊號約 13.4 次，死叉版約 1.4 次。出場原因：主策略 31% 為停損（平均 −12.6%）、69% 為賣出訊號（平均 +7.3%）；死叉版 48% 為停損（−12.7%）、52% 為賣出訊號（+20.8%）。

## 7. 交叉驗證（8 折）

2010–2019 與 2020 年在當初研究設計的樣本內，所以這些折看的是「不同市況下的行為」；真正沒看過的只有 2021–2026。

## 10. 已知弱點與注意事項

1. **訊號沒有資訊**：事件研究、對照組、交叉驗證三方面都顯示「零軸下 KDJ 與 MACD 同時翻揚」對之後報酬沒有預測力；規則的績效主要由「持有多少時間」與「交易成本」決定。
2. **主策略的賣出條件太敏感**：柱狀體在多頭中經常勾頭向下，賣在主升段的第一次回檔。若真的要用，至少把「MACD 往下」讀成 MACD 死叉（變體），但那也只是更接近買進持有。
3. **停損是收盤確認**：與 MultiCharts 的 `Close < EntryPrice * 0.9 → Sell next bar at market` 一致，但實際虧損常大於 10%（平均 −12.6%）；改用盤中停損（SetStopLoss）會得到不同的結果，未測試。
4. **急跌時會接刀**：空頭中零軸下的小反彈很多，turn 在 2011、2015 急跌段的持股率反而上升到 56～59%。
5. **多重測試**：本研究樣本內測了 149 組設定、交叉驗證 72 組（共 221 筆記錄於 `research/trials.jsonl`）。發布版本是字面讀法而不是最佳化結果，但變體的「MACD 死叉」讀法是看了樣本內結果才選的。
6. **倖存者偏差**：成分股是 2026 年 10 月的名單（事後贏家），讓買進持有基準特別強，對低持股率的策略特別不利。
7. **資料**：回測用還原權值日線、未計滑價；MultiCharts 若用未還原資料，除權息缺口會改變 KDJ、MACD 與停損判斷。
8. **單一參數組**：50 檔共用一組參數；金融股與電子股的波動差很多，10% 停損對低波動股很少觸發、對高波動股常常觸發，但分股調參的過度擬合風險更大，所以沒有做。

## 11. MultiCharts 對應與前瞻檢查

- `multicharts/kdj_macd_rebound_turn.txt`、`multicharts/kdj_macd_rebound_deadcross.txt`。KDJ：`hh = Highest(High,9); ll = Lowest(Low,9); rsv = (Close-ll)/(hh-ll)*100`（hh = ll 時 50）、`kv = kv[1]*2/3 + rsv/3`、`dv = dv[1]*2/3 + kv/3`、`jv = 3*kv - 2*dv`（初值 50）；
  MACD：`dif = XAverage(Close,12) - XAverage(Close,26); macdv = XAverage(dif,9); osc = dif - macdv`。
  停損以 `barsIn = 1` 時記錄的開盤價（= 成交價）為進場價，`Close < entryPx * (1 - StopPct/100)` 時隔天開盤以市價賣出。
- 我把兩支 PowerLanguage 程式逐行翻譯回 Python 逐根模擬（series 變數在第一根計算前為宣告初值、XAverage 由第一根計算的價格開始）：
  從第 1 根開始計算時，與 `strategy.py` 的部位在 50 檔、21.4 萬根 K 棒（暖機 60 根之後）上**完全一致（0 根不同）**；
  若 MultiCharts 因 MaxBarsBack 從第 10 根才開始計算，因 EMA 起點不同，主策略有 40 根（0.019%）、變體有 624 根（0.29%）部位不同。請至少載入 100 根以上的歷史資料。
- `--lookahead`：兩個策略在三個截斷點（2014-06-30、2018-03-30、2022-09-30）皆 **0 根 K 棒不同**。
- `build(預設參數)` 與發布的 `positions` 逐根相同；`strategy.py` 與研究程式在兩個 36 組格子上逐根相同。
