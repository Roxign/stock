{ ================================================================================
  kd_macd_rule_classic_zone：KD 低檔黃金交叉 + MACD 柱狀體確認（傳統對照組，只做多，部位 0 或 100%）
  --------------------------------------------------------------------------------
  規則（日K，每根K棒收盤後判斷，下一根K棒開盤以市價成交）：
    進場：K < 20 時 KD 黃金交叉（K 由下往上穿越 D），且 MACD 柱狀體（OSC = DIF - 訊號線）比前一根高。
    出場：K > 80 時 KD 死亡交叉（K 由上往下穿越 D），且 MACD 柱狀體比前一根低。
    這是台灣常見「KD 低檔金叉 + MACD 綠柱縮短/紅柱變長」的教科書組合，作為對照組使用；
    研究結果顯示它的報酬與 Sharpe 都明顯落後買進持有，詳見 RESEARCH.md。

  Inputs：
    KLen               KD 的 RSV 天數（預設 9；K、D 平滑固定為 1/3，即台灣常用 9,3,3 KD）
    MacdFast/Slow/Sig  MACD 參數（預設 12 / 26 / 9）
    OSLevel            KD 超賣門檻（預設 20）
    OBLevel            KD 超買門檻（預設 80）
    Capital            計算下單股數用的本金，請與 Strategy Properties 的 Initial Capital 相同

  注意：
    - 請在 Strategy Properties 設定交易成本：手續費買賣各 0.1425%（依券商折扣調整），
      證交稅賣出 0.3%（若無法只對賣方收稅，可把每邊佣金多加 0.15% 近似），以及合理滑價。
    - Python 回測使用還原權值（除權息調整）日線；MultiCharts 若使用未還原資料，
      除權息缺口會讓 KD、MACD 與訊號略有不同。
    - 指標需要暖機，請至少載入 100 根以上歷史K線；最前面幾十根的指標值可能與 Python 不同。
    - 下單股數 =（本金 + 已實現損益）÷ 收盤價，取整數股（零股）；若只交易整張請改成 1000 股的倍數。
  ================================================================================ }

Inputs:
	KLen(9),
	MacdFast(12),
	MacdSlow(26),
	MacdSig(9),
	OSLevel(20),
	OBLevel(80),
	Capital(1000000);

Vars:
	rsv(50), kv(50), dv(50), hh(0), ll(0),
	dif(0), macdv(0), osc(0),
	inTrade(false), shs(0);

{ ---- 台灣 KD（9,3,3，1/3 平滑，初值 50） ---- }
hh = Highest(High, KLen);
ll = Lowest(Low, KLen);
if hh - ll <> 0 then
	rsv = (Close - ll) / (hh - ll) * 100
else
	rsv = 50;
kv = kv[1] * 2 / 3 + rsv / 3;
dv = dv[1] * 2 / 3 + kv / 3;

{ ---- MACD：DIF = EMA12 - EMA26，訊號線 = DIF 的 EMA9，柱狀體 OSC = DIF - 訊號線 ---- }
dif = XAverage(Close, MacdFast) - XAverage(Close, MacdSlow);
macdv = XAverage(dif, MacdSig);
osc = dif - macdv;

{ ---- 狀態機 ---- }
if inTrade = false then begin
	if kv > dv and kv[1] <= dv[1] and kv < OSLevel and osc > osc[1] then
		inTrade = true;
end
else begin
	if kv < dv and kv[1] >= dv[1] and kv > OBLevel and osc < osc[1] then
		inTrade = false;
end;

{ ---- 下單：0 / 100% 部位 ---- }
if inTrade and MarketPosition = 0 then begin
	shs = IntPortion((Capital + NetProfit) / Close);
	if shs > 0 then
		Buy ("LE") shs shares next bar at market;
end;

if inTrade = false and MarketPosition = 1 then
	Sell ("LX") next bar at market;
