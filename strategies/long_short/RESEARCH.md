# 多空策略研究筆記

（2026-10-08；資料至 2026-10-02；放空依 `research/short_rules.md` 的台灣融券規則）

## 動機

使用者希望可以放空。`research/diagnosis.md` 的事前預測是：本專案的策略空手時，股價在一般時期仍然上漲（年化 +10%～+45%），只有空頭年才下跌；所以「把賣出訊號改成放空」很可能虧錢，放空只該在確認空頭時進行。這裡把這個預測實際測試一次。所有參數沿用既有策略或教科書預設值，沒有針對樣本外調整。

## 結果（中位數：年化報酬 / 最大回撤 / Sharpe）

**個股（50 檔）**

| 策略 | 樣本內 2010–2020 | 樣本外 2021–今 |
|---|---|---|
| 買進持有 | 8.8% / −46.1% / 0.48 | 35.7% / −45.5% / 1.10 |
| 均線趨勢減碼（只做多，對照） | 6.5% / −41.6% / 0.46 | 31.1% / −38.5% / 1.05 |
| 趨勢＋空頭才放空 | 2.6% / −50.8% / 0.24 | 24.4% / −44.4% / 0.86 |
| KDJ+MACD 反彈・多空 | −10.6% / −80.8% / −0.32 | −17.1% / −79.8% / −0.52 |

**ETF（0050、黃金、石油、美債；各 ETF 上市後才開始）**

| 策略 | 樣本內 | 樣本外 |
|---|---|---|
| 買進持有 | 6.1% / −24.5% / 0.50 | 17.7% / −35.2% / 0.68 |
| 趨勢追蹤・只做多 | 2.2% / −21.2% / 0.25 | 11.9% / −22.7% / 0.63 |
| 趨勢追蹤・多空 | −3.7% / −40.9% / −0.18 | 5.6% / −28.3% / 0.44 |
| KDJ+MACD 反彈・多空 | −6.3% / −40.7% / −0.38 | −11.3% / −57.3% / −0.50 |

## 解讀

1. **預測成立：放空讓結果更差。** 每一個多空版本都比對應的只做多版本差，個股上尤其明顯。
2. **KDJ+MACD 反彈規則的放空端特別糟**：「K 與 MACD 柱在零軸上同時轉弱」在多頭裡很常出現，但之後股價多半繼續上漲；放空後常被 10% 停損或維持率追繳打出場，加上每次放空約 0.67% 的來回成本（含 0.3% 證交稅與 0.08% 融券手續費）。
3. **只在大盤空頭時放空也沒有幫助**：空頭期間常出現急速反彈（2020、2022 年底），放空部位在反彈中虧損；加上除權息前的強制回補讓空單必須反覆進出。
4. **倖存者偏差讓個股放空看起來更差**：50 檔是今天的贏家，回測裡被放空的股票後來都漲回來；真實世界的放空對象會包含後來被剔除的弱勢股。
5. **ETF 的趨勢追蹤只做多版本有價值**：報酬較低，但最大回撤從 −35% 降到 −23%（樣本外）。改成多空後，黃金、美債的下跌趨勢不夠持續，放空反而虧損。

## 結論

在台股權值股與這幾檔 ETF 上，放空沒有改善報酬或風險調整後報酬；比較有用的方向是「不持有股票時，把資金放到其他資產」（見 `strategies/multi_asset`）。多空策略保留在網頁上，作為「放空為什麼不划算」的實證。
